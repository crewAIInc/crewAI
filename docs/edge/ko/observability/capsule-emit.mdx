# Agent Action Capsule 개요

[capsule-emit](https://github.com/action-state-group/capsule-emit)은 크루 실행의 각 도구 호출을 **Agent Action Capsule** 체인으로 기록합니다: 호출 시작 시 *계획* 캡슐이 봉인되고, 종료 시 *확인*(또는 *오류*) 캡슐이 봉인되어 캡슐 id로 계획 캡슐에 연결됩니다. 캡슐은 크루가 실제로 수행한 일에 대한 감사·컴플라이언스 증거이며 — 추적을 보완합니다.

의도적으로 구분된 두 검증 계층:

- **오프라인 `verify()`**는 구조, 콘텐츠 주소화(모든 다이제스트가 레코드 자체 내용에서 재계산됨), 체인 일관성을 검사합니다 — 서비스도 자격 증명도 필요 없습니다.
- **외부 당사자를 향한 변조 증거**는 앵커링 단계에서 나옵니다: 캡슐 다이제스트가 SCITT 투명성 로그에 등록되며, 로그의 영수증이 사후 변경을 외부인에게 드러나게 만듭니다. 퀵스타트는 데모의 밀폐성을 위해 이 단계를 로컬 스텁 서비스로 실행하며, 프로덕션 앵커링은 실제 로그를 가리킵니다.

### 기능

- **리스너 하나로 모든 도구 호출 기록**: CrewAI의 표준 `BaseEventListener` 메커니즘으로 `CapsuleEventListener()`를 한 번만 등록 — 도구별 코드 변경 없음.
- **계획 → 확인 체인**: 도구 호출 시작 시 계획 캡슐이 봉인되고, 종료 시 두 번째 확인 캡슐이 봉인되어 연결됩니다(`prior_capsule_id`); 오류는 연결된 실패 효과 캡슐을 봉인합니다.
- **다이제스트 전용 프라이버시**: 도구 입출력은 SHA-256 다이제스트로 커밋 — 원본 콘텐츠는 로컬에 유지되며, 다이제스트만 앵커링됩니다.
- **오프라인 일관성 검사**: `verify()`가 레코드만으로 구조, 콘텐츠 주소화, 체인 링크를 재검사합니다.
- **앵커링된 변조 증거**: SCITT 투명성 로그에 다이제스트 전용 등록; 영수증이 독립적 변조 증거의 핵심 단계입니다.
- **크루 안전 보장**: 리스너는 `is_replaying()`을 준수하고 크루 실행에 예외를 발생시키지 않습니다; 앵커에 접속할 수 없어도 크루는 중단되지 않습니다.

## 설정 방법

<Steps>
    <Step title="CrewAI 엑스트라와 함께 capsule-emit 설치">
      ```shell
      pip install "capsule-emit[crewai]"
      ```
    </Step>
    <Step title="리스너 등록">
      ```python
      from capsule_emit.adapters.crewai_listener import CapsuleEventListener

      # Register once, before kickoff — every tool call in the crew seals a capsule.
      listener = CapsuleEventListener()
      ```
    </Step>
    <Step title="평소처럼 크루 실행">
      ```python
      result = crew.kickoff()
      ```
      이제 각 도구 호출이 로컬 원장(기본값 `ledger.jsonl`)에 봉인된 레코드를 생성하며, 다이제스트는 구성된 SCITT 투명성 서비스에 앵커링됩니다.
    </Step>
    <Step title="증거 확인">
      ```python
      import json
      from agent_action_capsule import verify

      rows = [json.loads(line) for line in open("ledger.jsonl") if line.strip()]
      ok = all(verify(row.get("capsule", row)).ok for row in rows)
      print(f"{len(rows)} capsules, verify: {'ALL OK' if ok else 'FAILURES'}")
      ```
    </Step>
</Steps>

## 실행 가능한 퀵스타트

패키지에 밀폐형 엔드투엔드 데모가 포함되어 있습니다(실제 CrewAI 이벤트 버스, 로컬 스텁 투명성 서비스, LLM 키·외부 서비스 불필요):

```shell
pip install "capsule-emit[crewai]"
python examples/crewai-listener/demo.py
```

## 기록되는 내용

| 필드 | 내용 |
|---|---|
| `action_id` / 도구 이름 | 이 캡슐이 기록하는 도구 호출 |
| 입력/출력 다이제스트 | SHA-256 커밋 — 원본 콘텐츠는 환경 밖으로 나가지 않음 |
| `effect` | `planned`, `executed`, `confirmed`, `errored` |
| `confirms` 체인 | 실행 캡슐이 계획 캡슐을 콘텐츠 주소로 인용 |
| 앵커 영수증 | SCITT 투명성 로그에 다이제스트 전용 등록(선택 사항, 기본 활성화) |

레코드 형식은 공개 사양(`draft-mih-scitt-agent-action-capsule`, IETF 개인 인터넷 드래프트)이며 Apache-2.0 참조 구현이 있습니다.
