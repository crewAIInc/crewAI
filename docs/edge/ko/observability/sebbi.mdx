# CrewAI를 위한 sebbi 영수증

[sebbi](https://sebbi.pro/receipts)는 crew가 수행하는 모든 단계에 누구나 확인할 수 있는 공개 링크가 포함된 봉인된 영수증을 제공합니다. 고객, 감사인, 보험사 또는 규제 기관 누구나 확인할 수 있습니다. 영수증은 머클 트리로 묶여 추가 전용 체인에 봉인되고, 독립적인 체인들이 증인으로 확인하며, 비트코인에 타임스탬프가 기록되므로 에이전트가 수행한 작업의 기록을 나중에 몰래 수정할 수 없습니다.

sebbi 클라이언트는 프로세스 내부에서 입력과 출력의 해시(SHA-256)를 계산하고, 지문과 짧은 레이블, 타임스탬프만 전송합니다. 클라이언트는 오픈 소스이므로 설치 전에 직접 확인할 수 있습니다: [github.com/justrightdecorators-ops/sebbi-sdk](https://github.com/justrightdecorators-ops/sebbi-sdk). 봉인은 백그라운드 스레드에서 실행되며 crew에 예외를 발생시키지 않습니다.

## 설치

검토한 릴리스를 고정하세요:

```bash
pip install "sebbi==1.1.1"
```

해당 저장소의 `main` 브랜치에 있는 버전이 PyPI에 게시된 버전이므로, 설치할 코드를 정확히 읽어볼 수 있습니다. 클라이언트에는 의존성이 없습니다.

시작하는 데 계정이 필요하지 않습니다(하루 1,000개 영수증). 전체 용량을 사용하려면 [sebbi.pro/connect](https://sebbi.pro/connect)에서 받은 `SEBBI_API_KEY`를 설정하세요.

## 사용법

```python
from crewai import Agent, Crew, Task
from sebbi.integrations.crewai import step_callback, task_callback

crew = Crew(
    agents=[...],
    tasks=[...],
    step_callback=step_callback,   # 모든 에이전트 단계에 대한 영수증
    task_callback=task_callback,   # 완료된 모든 작업에 대한 영수증
)

result = crew.kickoff()
```

최신 영수증 링크 가져오기:

```python
import sebbi
print(sebbi.last().url)   # https://sebbi.pro/r/...
```

## 특정 작업 봉인하기

에이전트가 호출하는 도구 함수를 감싸세요:

```python
import sebbi

@sebbi.receipt("issue-refund")
def issue_refund(order_id: str, amount: float) -> dict:
    ...
```

## 취소(되돌리기)

작업이 취소되면(환불, 결제 취소 등) 취소를 봉인하세요. 원래 영수증은 기록에 그대로 남고, 새 영수증 및 사유와 연결되어 취소됨으로 표시됩니다:

```python
sebbi.reverse(receipt, "고객 취소; 환불 완료")
```

## 영수증 확인하기

영수증 링크를 열거나 `GET https://sebbi.pro/v1/receipts/<id>`를 호출하세요. 확인할 때마다 머클 포함 증명을 다시 실행하고 루트가 체인에 봉인되어 있는지 확인합니다.
