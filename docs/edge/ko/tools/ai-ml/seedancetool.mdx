Ace Data Cloud에서 제공하는 이 패키지로 CrewAI에서 Seedance 서비스를 사용할 수 있습니다.

## 설치

```bash
uv add crewai-seedance==0.1.0
```

Seedance 서비스에 접근할 수 있는 [애플리케이션 API 토큰](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=seedancecrewai_docs_api_key)을 발급하고 환경 변수 `ACEDATACLOUD_API_KEY`에 저장하세요. 미디어를 생성하기 전에 [현재 요금](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=seedancecrewai_docs_pricing)을 확인하세요.

## 사용법

입력은 일반 prompt가 아닌 텍스트/이미지/오디오/비디오의 구조화 content입니다. 소문자 resolution과 ratio, 모델이 지원하는 길이/오디오 옵션을 사용합니다. 결과는 data.video_url 또는 data.content.video_url입니다.

에이전트의 `tools` 목록에 `SeedanceGenerateVideoTool()` 및 `SeedanceRetrieveTaskTool()`를 추가하세요. 생성 도구는 작업 ID를 반환합니다. 진행 상황을 확인하려면 작업을 제출한 키로 같은 ID를 조회하세요.

```python
from seedance_crewai import SeedanceRetrieveTaskTool

result = SeedanceRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```
