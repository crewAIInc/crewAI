# `SerpKiteSearchTool`

이 통합은 SerpKite 팀이 유지 관리하며 `serpkite[crewai]`로 배포됩니다. `crewai-tools`에 포함되지 않습니다.

## 설치

패키지를 설치하고 [SerpKite](https://app.serpkite.com/keys)에서 발급받은 키를 `SERPKITE_API_KEY`에 설정하세요.

```shell
uv add "serpkite[crewai]"
export SERPKITE_API_KEY="skt_live_..."
```

## 사용법

이 도구는 검색 결과와 출처 링크를 포함하는 Markdown을 반환합니다. CrewAI 에이전트에 직접 전달하세요. 사용할 LLM 공급자는 별도로 설정하세요.

```python
from crewai import Agent
from serpkite.crewai import SerpKiteSearchTool

search = SerpKiteSearchTool()
print(search.run(query="latest Python release"))

researcher = Agent(
    role="Researcher",
    goal="Find current information and cite sources",
    backstory="You research public information using web search.",
    tools=[search],
)
```

## 설정

`endpoint`에는 `search`(기본값), `news`, `images`, `videos`, `maps`, `places`, `shopping`, `scholar`, `patents`, `autocomplete`를 지정할 수 있습니다. `country`, `language`, `location`, `num`의 기본값을 설정할 수 있습니다. 에이전트는 `query`, `num`, `country`, `language`, `time`(`hour`, `day`, `week`, `month`, `year`)을 전달할 수 있습니다.

모든 엔드포인트가 모든 옵션을 지원하는 것은 아닙니다. 예를 들어 `scholar`는 `time`을 지원하지 않습니다. 엔드포인트별 옵션을 설정하기 전에 [엔드포인트 참조](https://serpkite.com/docs)를 확인하세요.

```python
news = SerpKiteSearchTool(endpoint="news", country="us", language="en", num=10)
print(news.run(query="renewable energy", time="week"))
```
