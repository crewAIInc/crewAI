# `ViaSocketTools`

## 설명

[viaSocket](https://viasocket.com)은 Slack, Google Sheets, HubSpot, Notion 등 2,300개 이상의 앱을 연결합니다. `ViaSocketTools`는 최종 사용자가 연결한 앱의 각 작업을 CrewAI 도구로 만들어 줍니다. 도구는 해당 사용자의 연결로 실행되므로, 커넥터 코드나 OAuth를 직접 구현하지 않고도 에이전트가 사용자의 앱에서 작업할 수 있습니다.

## 설치

```shell
uv add viasocket
```

## 환경 변수

- `VIASOCKET_ORG_ID`, `VIASOCKET_PROJECT_ID`, `VIASOCKET_EMBED_SECRET` (필수): 프로젝트에서 `npx viasocket-apps setup`을 실행하거나 viaSocket 대시보드(**Integrations → Create embed → Install Code**)에서 복사하세요. `org_id`, `project_id`, `secret`을 직접 전달할 수도 있습니다.

최종 사용자는 제품 안에서 viaSocket의 연결 팝업으로 앱을 연결합니다. 먼저 사용해 보려면 터미널에서 직접 앱을 연결하세요:

```shell
npx viasocket-apps connect slack --user me
```

## 예시

```python Code
from crewai import Agent, Task, Crew
from crewai_tools import ViaSocketTools

tools = ViaSocketTools(
    user="me",  # the end user the apps were connected for
    apps=["slack"],
    actions={"slack": ["send-message"]},
)

agent = Agent(
    role="Operations assistant",
    goal="Keep the team updated in Slack",
    backstory="You post updates where the team reads them.",
    tools=tools,
    verbose=True,
)

task = Task(
    description="Post a short summary of today's release in the #general channel",
    agent=agent,
    expected_output="Confirmation that the message was posted",
)

crew = Crew(agents=[agent], tasks=[task])
result = crew.kickoff()
```

## 매개변수

- `user` (필수): 최종 사용자의 앱이 연결된 고유 식별자입니다.
- `apps` (필수): 앱의 slug 목록입니다 (`slack`, `google-sheets`, `hubspot`).
- `actions` (선택): 앱별 작업을 경로 또는 `action_id`로 지정합니다 (`{"slack": ["send-message"]}`). 지정하지 않은 앱은 게시된 모든 작업을 도구로 제공합니다.

## 참고

- 도구 이름은 `slack_send-message`처럼 `<app>_<action>` 형식입니다. 각 도구의 입력은 작업의 양식에서 만들어지므로, 에이전트는 사람이 보는 것과 같은 필드와 도움말을 봅니다.
- ID를 담는 필드(채널, 시트)는 앱의 `<app>_list-options` 도구로 채우며, 이 도구는 사용자 계정의 실제 값을 읽어 옵니다.
- 사용자가 앱을 연결하지 않았거나 앱이 오류를 반환하면, 에이전트는 예외 대신 일반 텍스트 응답을 받습니다.
