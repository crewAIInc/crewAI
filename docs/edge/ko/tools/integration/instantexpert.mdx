# Instant Expert

[Instant Expert](https://instant.expert)를 사용하면 에이전트가 비용을 지불할 가치가 있는 특정 인물, 즉 임원, 실무 책임자, 도메인 전문가에게서 답을 얻을 수 있습니다. 설명에 맞는 사람을 찾거나 지정한 사람을 그대로 사용하고, 각 사람에게 짧은 통화나 서면 답변을 요청하는 유료 초대를 보내며, 상대가 예약하거나 답변한 경우에만 요금이 청구됩니다. 원격 MCP 서버이므로 CrewAI는 내장 MCP 지원, 즉 에이전트의 `mcps`에 넣는 `MCPServerHTTP`로 연결하며 별도의 패키지를 설치할 필요가 없습니다.

| 엔드포인트                        | 연결 대상                                                      | 인증                          |
| --------------------------------- | -------------------------------------------------------------- | ----------------------------- |
| `https://instant.expert/mcp/test` | 테스트 모드: 가상의 인물, 이메일 발송 없음, Stripe 테스트 카드 | 무료 샌드박스 토큰, 계정 불필요 |
| `https://instant.expert/mcp`      | 실제 계정: 실제 인물과 실제 결제                               | 해당 계정의 OAuth 액세스 토큰 |

## 요구 사항

- CrewAI (`MCPServerHTTP`가 사용하는 `mcp` 라이브러리가 포함되어 있습니다)
- LLM API 키 (예: `OPENAI_API_KEY`)
- 테스트 모드에는 Instant Expert 계정이 필요하지 않습니다

## 테스트 모드 토큰 받기

테스트 모드는 가상의 인물을 사용하고, 이메일을 보내는 대신 기록하며, Stripe 테스트 카드로 결제합니다. 요청 한 번으로 24시간 동안 유효한 토큰을 받을 수 있습니다:

```bash
curl -X POST https://instant.expert/api/sandbox
export INSTANT_EXPERT_SANDBOX_TOKEN=ie_sandbox_...
```

네트워크마다 한 시간에 토큰을 5개까지 만들 수 있으므로, 여러 번 실행할 때는 토큰 하나를 재사용하세요.

## 사용법

`before_tool_call` 훅은 주문을 실행하는 도구인 `send_requests`에서 크루를 멈추고, 사람이 승인할 때까지 기다립니다.

```python
import os

from crewai import Agent, Crew, Task
from crewai.hooks import ToolCallHookContext, before_tool_call
from crewai.mcp import MCPServerHTTP

instant_expert = MCPServerHTTP(
    url="https://instant.expert/mcp/test",
    headers={"Authorization": f"Bearer {os.environ['INSTANT_EXPERT_SANDBOX_TOKEN']}"},
)


@before_tool_call
def approve_paid_send(context: ToolCallHookContext) -> bool | None:
    # CrewAI prefixes MCP tool names with the server, so match the suffix.
    if not context.tool_name.endswith("send_requests"):
        return None
    answer = context.request_human_input(
        prompt=f"Place this order? {context.tool_input}",
        default_message="Type y to send:",
    )
    return None if answer.strip().lower() == "y" else False  # False blocks the call


coordinator = Agent(
    role="Outreach coordinator",
    goal="Get answers from the right executives and report each person's outcome",
    backstory="You find the right people through Instant Expert and only spend within budget.",
    mcps=[instant_expert],
)
outreach = Task(
    description=(
        "Find 3 product leaders at SaaS companies. Offer each of them $40 for a "
        "15-minute call about how they choose analytics tools, with a $150 total "
        "budget. Search, wait for the job with get_job, read the people with "
        "get_search, draft with queue_requests, then preview with "
        "prepare_request_order. Then call send_requests right away with the "
        "preview's details and confirmed=true. Don't ask for approval in chat: "
        "the crew pauses at send_requests and shows the founder the order. "
        "Finally, report who booked, replied or declined."
    ),
    expected_output="Who was invited, the price, and each person's status",
    agent=coordinator,
)
print(Crew(agents=[coordinator], tasks=[outreach]).kickoff().raw)
```

테스트 모드에서는 초대가 전달된 뒤 각 가상 인물이 스스로 응답합니다. 일부는 예약하고, 일부는 질문으로 답장하고, 일부는 거절하며, 일부는 끝내 답하지 않습니다.

## 사용 가능한 도구

| --------------------------------------------------- | --------------------------------------------------------------------- |
| `plan_outreach`                                     | 회사나 리서치 질문에 맞는, 연락할 가치가 있는 대상 그룹을 제안합니다  |

## 실제 계정으로 전환

실제 계정은 `https://instant.expert/mcp`를 사용하며, 샌드박스 토큰 대신 OAuth 액세스 토큰을 보냅니다. API 키는 없습니다. 서버는 OAuth 2.1(PKCE와 동적 클라이언트 등록)로 클라이언트를 로그인시킵니다. `MCPServerHTTP`는 전달한 헤더만 보내므로, 로그인을 수행하는 MCP 클라이언트(예: FastMCP)로 토큰을 받으세요. pip가 CrewAI의 `mcp` 라이브러리 버전과 호환되는 FastMCP 릴리스를 고르도록, CrewAI와 같은 명령으로 설치하세요: `pip install crewai fastmcp`.

```python
import asyncio

from crewai.mcp import MCPServerHTTP
from fastmcp import Client
from fastmcp.client.auth import OAuth

LIVE_URL = "https://instant.expert/mcp"


async def sign_in() -> str:
    """Sign in to Instant Expert in the browser and return an access token."""
    oauth = OAuth(mcp_url=LIVE_URL)
    async with Client(LIVE_URL, auth=oauth):
        tokens = await oauth.token_storage_adapter.get_tokens()
    return tokens.access_token


instant_expert = MCPServerHTTP(
    url=LIVE_URL,
    headers={"Authorization": f"Bearer {asyncio.run(sign_in())}"},
)
```

`sign_in()`은 실행마다 한 번 브라우저를 열어 로그인하고 연결을 승인하게 합니다. CrewAI는 실행 내내 이 헤더를 바꾸지 않고 그대로 보내며, 액세스 토큰은 짧은 시간 뒤에 만료되므로 토큰이 만료되기 전에 승인을 포함한 실행을 마치세요. 도구 호출이 HTTP 401로 실패하기 시작하면 다시 로그인하고 새로 실행하세요. 그 전에 실행된 주문은 그대로 남아 있으므로, 다시 발송하기 전에 `list_requests`로 확인하세요. 에이전트가 주문을 실행하려면 해당 연결에서 유료 발송을 켜고 카드를 저장해 두어야 합니다. 자세한 내용은 [Instant Expert MCP 문서](https://instant.expert/docs/mcp)를 참고하세요.

## 참고

- CrewAI는 MCP 도구 이름 앞에 서버 이름을 붙입니다. 테스트 모드에서는 `instant_expert_mcp_test_send_requests`, 실제 계정에서는 `instant_expert_mcp_send_requests`가 됩니다. 훅은 이름의 끝부분을 비교하므로 두 경우 모두 동작합니다.
- CrewAI는 서버 자체의 지침을 모델에 전달하지 않으므로, 위 작업 설명에 그 지침이 안내하는 단계(검색, 작업 대기, 인물 확인, 초안 작성, 미리 보기, 발송)를 직접 적어 두었습니다.
- CrewAI는 30초 넘게 실행되는 도구 호출을 재시도합니다. 작업을 시작하거나 주문을 실행하는 도구는 멱등성 키를 받으며, 같은 인수로 재시도하면 원래의 작업이나 주문이 반환되므로 안전합니다.
