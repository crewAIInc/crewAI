# Lians 에이전트 메모리 도구

[Lians](https://www.lians.ai/)는 에이전트 메모리를 저장하고, 검색하고, 특정 시점으로 재생하고, 플러시하는 네 가지 CrewAI 도구를 제공합니다. API 키 없이 로컬에서 실행하거나 원격 Lians 서비스에 연결할 수 있습니다.

## 설치

CrewAI와 Lians CrewAI 통합을 설치합니다. 설정이 필요 없는 로컬 저장소를 사용하려면 `local` extra를 포함하세요.

```bash
pip install crewai "lians-sdk[crewai,local]"
```

## 사용법

로컬 클라이언트를 만들고 도구를 빌드한 다음 에이전트에 연결합니다.

```python
from crewai import Agent, Crew, Task
from lians import LocalLiansClient
from lians.crewai_integration import build_crewai_tools

with LocalLiansClient() as client:
    memory_tools = build_crewai_tools(client, agent_id="research-crew")

    researcher = Agent(
        role="Researcher",
        goal="Build on verified findings from earlier research",
        backstory="You preserve useful evidence and retrieve it when relevant.",
        tools=memory_tools,
        verbose=True,
    )

    task = Task(
        description="Research the topic, recall relevant prior findings, and save new evidence.",
        expected_output="A concise research brief with the useful findings saved to memory.",
        agent=researcher,
    )

    result = Crew(agents=[researcher], tasks=[task]).kickoff()
    print(result)
```

## 사용 가능한 도구

| 도구 | 용도 |
|:-----|:--------|
| `remember_fact` | 출처와 신뢰도 메타데이터를 포함해 사실 저장 |
| `recall_facts` | 현재 질의와 관련된 메모리 검색 |
| `recall_facts_at` | 지정된 시점에 에이전트가 알고 있던 내용 재구성 |
| `flush_memory` | 대기 중인 메모리 업데이트 영구 저장 |

여러 크루 실행이 같은 메모리 기록을 공유해야 한다면 안정적인 `agent_id`를 사용하세요. 실행별로 메모리를 분리해야 한다면 다른 ID를 사용하세요.

## 원격 서비스

배포된 Lians 서비스를 사용하려면 서비스 URL과 자격 증명으로 표준 Lians 클라이언트를 만들고, `LocalLiansClient` 대신 `build_crewai_tools`에 전달하세요.

```python
import os

from lians import LiansClient
from lians.crewai_integration import build_crewai_tools

with LiansClient(
    base_url=os.environ["LIANS_BASE_URL"],
    api_key=os.environ["LIANS_API_KEY"],
) as client:
    memory_tools = build_crewai_tools(client, agent_id="research-crew")
    # 클라이언트가 열린 상태를 유지하도록 이 블록 안에서 Agent/Crew를 만들고 실행하세요.
```

설정과 API 세부 정보는 [Lians 문서](https://www.lians.ai/docs)를 참조하세요.
