# `ScrapewiseProductDataTool`

## 설명

`ScrapewiseProductDataTool`은 관리형 이커머스 스크래핑 플랫폼인 [ScrapeWise](https://scrapewise.ai)에서 구조화된 제품 및 가격 행을 읽어옵니다. 스크레이퍼의 실행과 유지 관리는 ScrapeWise가 담당하며, 이 도구는 이미 저장된 행 — 제목, 가격, 재고 여부, 제품 식별자 — 을 읽기만 합니다. 따라서 에이전트가 직접 HTML을 가져오거나 파싱하지 않습니다.

이 점이 같은 카테고리의 실시간 스크래핑 도구들과 다른 부분입니다. 페이지 요청도, 봇 차단 벽도, 도구 출력에 포함되는 HTML도 없습니다. 그 대가로, 대상 사이트가 ScrapeWise 계정에 스크레이퍼로 미리 설정되어 있어야 합니다.

## 설치

이 도구를 사용하려면 ScrapeWise Python 클라이언트를 설치해야 합니다:

```shell
uv add scrapewise
```

또한 ScrapeWise API 키를 환경 변수로 설정해야 합니다:

```shell
export SCRAPEWISE_API_KEY="your_api_key"
```

API 키는 [ScrapeWise 대시보드](https://portal.scrapewise.ai)에서 발급받을 수 있습니다.

## 시작하는 단계

`ScrapewiseProductDataTool`을 효과적으로 사용하려면 다음 단계를 따라주세요:

1. **의존성 설치**: 위 명령어를 사용하여 필요한 패키지를 설치합니다.
2. **API 키 설정**: ScrapeWise API 키를 환경 변수로 설정하거나 초기화 시에 제공합니다.
3. **스크레이퍼 ID 확인**: ScrapeWise 대시보드에서 데이터를 읽어올 스크레이퍼의 id를 복사합니다.
4. **도구 초기화**: 도구를 하나의 스크레이퍼에 고정하거나, `scraper_id`를 생략하고 에이전트가 호출마다 전달하도록 합니다.

## 예시

다음 예시는 `ScrapewiseProductDataTool`을 사용하여 경쟁사 가격을 읽어오는 방법을 보여줍니다:

```python Code
from crewai import Agent, Task, Crew
from crewai_tools import ScrapewiseProductDataTool

# Initialize the tool, pinned to one scraper
product_data_tool = ScrapewiseProductDataTool(scraper_id="68d4f1c9ab12cd34ef567890")

# Define an agent that uses the tool
pricing_analyst = Agent(
    role="Pricing Analyst",
    goal="Understand how competitor prices move across a product range",
    backstory="An analyst who works from structured product feeds rather than raw web pages.",
    tools=[product_data_tool],
    verbose=True,
)

# Example task to summarise competitor pricing
pricing_task = Task(
    description="Read the latest competitor product rows and report the ten cheapest in-stock items.",
    expected_output="A ranked list of ten products with price and availability.",
    agent=pricing_analyst,
)

# Create and run the crew
crew = Crew(agents=[pricing_analyst], tasks=[pricing_task])
result = crew.kickoff()
```

`scraper_id`를 생략하면 에이전트가 호출마다 소스를 선택할 수 있습니다:

```python Code
product_data_tool = ScrapewiseProductDataTool()
```

## 인수

`ScrapewiseProductDataTool`은 초기화 시 다음 인수를 받습니다:

- `scraper_id`: 선택 사항. 도구를 단일 ScrapeWise 스크레이퍼에 고정합니다. 설정하면 에이전트가 더 이상 이를 제공할 필요가 없습니다.
- `api_key`: 선택 사항. ScrapeWise API 키입니다. 지정하지 않으면 `SCRAPEWISE_API_KEY` 환경 변수를 사용합니다.
- `base_url`: 선택 사항. API 기본 URL을 재정의합니다. 기본값이 아닌 배포 환경에서만 필요합니다.
- `timeout`: 선택 사항. 요청 타임아웃(초)입니다.

호출 시에는 다음 인수를 받습니다:

- `scraper_id`: 초기화 시 고정하지 않았다면 필수입니다.
- `max_rows`: 선택 사항, 기본값 `25`. 1에서 100 사이여야 합니다.

## 환경 변수

- `SCRAPEWISE_API_KEY`: 필수. ScrapeWise API 키입니다.

## 행 수 제한

ScrapeWise 샘플 데이터 엔드포인트는 호출당 최대 100개의 행을 반환하므로, `max_rows`는 이 상한을 기준으로 검증됩니다. 이는 저장된 행의 샘플이며 전체 데이터셋이 아닙니다 — 전체 볼륨 분석에는 ScrapeWise 내보내기를 사용하세요.

## 오류 처리

이 도구는 예외를 발생시키는 대신 오류를 텍스트로 반환하므로, 읽기에 실패해도 크루가 중단되지 않습니다:

- `scrapewise` 패키지가 없으면 초기화 시점에 설치 명령어를 담은 `ImportError`가 발생합니다.
- API 키가 없으면 초기화 시점에 `ValueError`가 발생합니다.
- 1–100 범위를 벗어난 `max_rows` 값은 입력 스키마에서 거부됩니다.
- API 및 전송 오류는 `Error reading ScrapeWise product data: ...` 형태로 반환됩니다.
- 저장된 행이 아직 없는 스크레이퍼는 빈 문자열이 아니라 그 사실을 알리는 명시적인 메시지를 반환합니다.

## 모범 사례

- 크루가 하나의 사이트만 읽는다면 `scraper_id`를 고정하세요 — 모델이 틀릴 수 있는 매개변수가 하나 줄어듭니다.
- 추론 작업에서는 `max_rows`를 낮게(25 이하) 유지하세요. 많은 행을 쏟아내면 컨텍스트 윈도우를 잠식합니다.
- 에이전트가 두 사이트를 비교할 때는 스크레이퍼마다 별도의 도구 인스턴스를 사용하고, 모델이 혼동하지 않도록 에이전트 이름에 사이트명을 넣으세요.
