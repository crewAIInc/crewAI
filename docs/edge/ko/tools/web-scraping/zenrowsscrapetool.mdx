# `ZenRowsScrapeTool`

## 설명

[Zenrows](https://www.zenrows.com/)는 안티봇 우회, 헤드리스 브라우저 JavaScript 렌더링, 레지덴셜 프록시 로테이션을 단일 HTTP 엔드포인트로 처리하는 웹 스크래핑 API입니다. `ZenRowsScrapeTool`은 URL 하나를 스크래핑해 그 내용을 markdown, plaintext, 또는 raw HTML로 반환합니다.

기본적으로 모든 요청은 [Adaptive Stealth Mode](https://docs.zenrows.com/universal-scraper-api/features/adaptive-stealth-mode)(`mode: "auto"`)로 전송됩니다. Zenrows는 가장 저렴한 설정으로 시작해 대상 페이지가 필요로 할 때만 JS 렌더링이나 프리미엄 프록시로 자동 확장하며, 성공한 설정에 대해서만 과금합니다. 이는 이 tool을 위한 의도적인 설계 선택입니다 — LLM이 페이지마다 올바르게 고를 방법이 없는 긴 안티봇 매개변수 목록(`js_render`, `premium_proxy`, `proxy_country` 등) 대신, 에이전트에게 노출되는 인터페이스를 `url`과 `response_type`만으로 유지합니다.

## 설치

- [zenrows.com](https://www.zenrows.com/)에서 API 키를 발급받아 `ZENROWS_API_KEY` 환경 변수에 설정하세요 (또는 `api_key=`를 직접 전달하세요).
- 추가 패키지는 필요 없습니다 — 이 tool은 이미 `crewai-tools`의 의존성인 `requests`를 사용합니다.

```shell
pip install 'crewai[tools]'
```

## 예제

```python Code
from crewai_tools import ZenRowsScrapeTool

tool = ZenRowsScrapeTool()

result = tool.run(url="https://example.com")
```

기본값인 markdown 대신 plaintext를 요청하려면:

```python Code
result = tool.run(url="https://example.com", response_type="plaintext")
```

## 고급 설정

특정 crew가 항상 필요로 하는 매개변수 — `js_instructions` 실행, 셀렉터 대기, 또는 `proxy_country` 고정 — 는 생성 시점에 `config`로 한 번만 설정하면 이 tool 인스턴스가 만드는 모든 요청에 적용됩니다.

```python Code
tool = ZenRowsScrapeTool(
    config={
        "mode": "auto",
        "proxy_country": "us",
    }
)
```

<Note>
  `proxy_country`는 `mode: "auto"`와 함께 사용할 수 있습니다 — Zenrows가 이를 위해 자동으로 `premium_proxy`를 활성화합니다. `mode: "auto"`가 아닌 경우에는 `proxy_country`를 사용하려면 `premium_proxy: True`를 명시적으로 설정해야 합니다. 그렇지 않으면 Zenrows가 프리미엄(레지덴셜) 프록시에만 지역 설정을 적용하므로 조용히 무시됩니다. `premium_proxy`(또는 `js_render`)를 `mode: "auto"`와 함께 수동으로 설정하는 것은 별개의, 여전히 유효하지 않은 조합입니다 — Adaptive Stealth Mode가 이 둘을 자체적으로 관리하며 수동으로도 설정되면 요청을 거부합니다. `ZenRowsScrapeTool`은 생성 시점에 두 규칙을 모두 검증하여, 조용히 실패하거나 요청 시점에야 실패하는 대신 `ValueError`를 발생시킵니다.
</Note>

Adaptive Stealth 대신 완전한 수동 제어를 원한다면:

```python Code
tool = ZenRowsScrapeTool(
    config={
        "js_render": True,
        "premium_proxy": True,
        "proxy_country": "us",
    }
)
```

전체 매개변수 레퍼런스는 [Zenrows API 문서](https://docs.zenrows.com/universal-scraper-api/api-reference)를 참고하세요.

## 인자

- `api_key`: 선택 사항. Zenrows API 키입니다. 기본값은 `ZENROWS_API_KEY` 환경 변수입니다.
- `config`: 선택 사항. 이 tool 인스턴스가 만드는 모든 요청에 병합되는 추가 Zenrows API 매개변수입니다. 기본값은 `{"mode": "auto"}` (Adaptive Stealth Mode)입니다.
- `timeout`: 선택 사항. 요청 타임아웃(초)입니다. JS 렌더링 페이지를 위해 기본값은 `140`입니다.

호출별(에이전트에 노출되는) 인자:

- `url`: 필수. 스킴을 포함한 스크래핑 대상 페이지의 전체 URL입니다.
- `response_type`: 선택 사항. `"markdown"`(기본값), `"plaintext"`, `"html"` 중 하나입니다.
