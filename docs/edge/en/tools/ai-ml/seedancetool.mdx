Ace Data Cloud maintains this package for using Seedance from CrewAI.

## Installation

```bash
uv add crewai-seedance==0.1.0
```

Create an [application API token](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=seedancecrewai_docs_api_key) with access to Seedance and set it as `ACEDATACLOUD_API_KEY` in your environment. Check the [current price](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=seedancecrewai_docs_pricing) before generating media.

## Usage

The input is structured `content` (text/image/audio/video references), not a generic prompt. Use lowercase resolution (`480p/720p/1080p/4k`), ratio and model-supported duration/audio options. Results use `data.video_url` or `data.content.video_url`.

Pass `SeedanceGenerateVideoTool()` and `SeedanceRetrieveTaskTool()` to your agent’s `tools` list. Generation returns a task ID. To check its progress, query the same ID with the key that submitted the task.

```python
from seedance_crewai import SeedanceRetrieveTaskTool

result = SeedanceRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```
