If restricting APIs, allow `/seedance/videos` and `/seedance/tasks`. Set the raw Token in environment variable `ACEDATACLOUD_API_KEY`, without Bearer or spaces; never put it in prompts or versioned files.

The input is structured `content` (text/image/audio/video references), not a generic prompt. Use lowercase resolution (`480p/720p/1080p/4k`), ratio and model-supported duration/audio options. Results use `data.video_url` or `data.content.video_url`.

For the first free check, retrieve a pre-existing task owned by that Key. This creates no media:

```python
from seedance_crewai import SeedanceRetrieveTaskTool

result = SeedanceRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```

After approving the generation model and budget, add `SeedanceGenerateVideoTool()` and `SeedanceRetrieveTaskTool()` to the Agent tools list. They are native BaseTool implementations with visible service names and schemas; no MCP setup is required. Generation submits one billable asynchronous request; preserve task_id and query the same ID. accepted/pending is not success. Do not regenerate to poll or after a timeout with unknown submission outcome.

Successful stored tasks return status=succeeded, success=true, media_urls and original Credits cost when available. Nested failed states or missing terminal media are structured ToolFailure, not success. HTTP meaning is preserved without dumping private response bodies. No automatic paid HTTP retry, payment handler or model fallback is added. One generation use per instance is not a funds cap or permission system.
