Install the reviewed standalone package from its exact source commit. This uses CrewAI BaseTool directly; no MCP setup or custom wrapper is needed.

```bash
uv add 'crewai-suno @ git+https://github.com/AceDataCloud/SunoCrewAI.git@5b3bc4d597f5fb046b1d6298d5e833ad7f2b29fb'
```

```bash
uv add 'crewai-suno @ https://github.com/AceDataCloud/SunoCrewAI/releases/download/v0.1.0/crewai_suno-0.1.0-py3-none-any.whl#sha256=c00d2d011c72f0b1d294ce020b06c20668ef8d4572aaffbc53874341bc707ecf'
```

Register or sign in to [Ace Applications](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=sunocrewai_docs_api_key). Open General application and copy an API-consumer Token, or use Manage Keys → Create for a dedicated key. Allow `/suno/audios` and `/suno/tasks` if restricting APIs. Set `ACEDATACLOUD_API_KEY` in your environment; never put the Key in a prompt or committed config.

Check current Suno permissions, balance and [model pricing](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=sunocrewai_docs_pricing) first. Adding a tool does not call it. `SunoGenerateMusicTool` submits a billable asynchronous request once; `SunoRetrieveTaskTool` only queries the original task ID. A pending result is not success.

For the first safe check, query a task you already own; this does not create music.

```python
from suno_crewai import SunoRetrieveTaskTool

result = SunoRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```

After approving a generation budget, pass `SunoGenerateMusicTool()` and `SunoRetrieveTaskTool()` to your Agent. Generation requires a current public model ID and returns `task_id`; preserve that ID. Do not regenerate to poll or after an unknown timeout. Each generation tool instance defaults to one use; this is not a funds cap.

Successful retrieval reports `status=succeeded`, `success=true`, `media_urls` and original Credits `cost` when supplied. Failed tasks use structured ToolFailure. HTTP 401/403/429/5xx retain their meaning; no automatic paid HTTP retry or model fallback is added. The package does not enable tracing or add a GUI.
