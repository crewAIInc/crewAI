# `WaveSpeedImageTool` and `WaveSpeedVideoTool`

## Description

These tools give the Agent the ability to generate images and videos with models hosted on [WaveSpeed AI](https://wavespeed.ai).

- `WaveSpeedImageTool` generates an image from a text prompt. When reference image URLs are given, it edits or combines them according to the prompt.
- `WaveSpeedVideoTool` generates a video from a text prompt. When an image URL is given, it animates that image.

Each call submits one prediction, waits for it to finish, and returns the URLs of the generated files as JSON.

## Installation

Install the crewai_tools package
```shell
pip install 'crewai[tools]'
```

Set your WaveSpeed AI API key as an environment variable:
```shell
export WAVESPEED_API_KEY="your-api-key"
```

## Example

Remember that when using these tools, the prompt must be generated by the Agent itself. It must describe the image or video you want to generate.

```python Code
from crewai_tools import WaveSpeedImageTool, WaveSpeedVideoTool

Agent(
    ...
    tools=[WaveSpeedImageTool(), WaveSpeedVideoTool()],
)
```

The image tool returns `{"image_urls": [...], "model": "...", "prediction_id": "..."}` and the video tool returns `{"video_url": "...", "model": "...", "prediction_id": "..."}`.

## Parameters

### Run parameters

`WaveSpeedImageTool`:
- **prompt**: Description of the image to generate.
- **images**: Optional list of reference image URLs to edit or combine.

`WaveSpeedVideoTool`:
- **prompt**: Description of the video to generate.
- **image**: Optional URL of an image to use as the first frame.

### Initialization parameters

`WaveSpeedImageTool`:
- **model**: Model used for text-to-image generation. Default is `bytedance/seedream-v5.5`.
- **edit_model**: Model used when reference images are given. Default is `bytedance/seedream-v5.5/edit`.
- **aspect_ratio**, **resolution**, **output_format**: Optional. Sent only when set, otherwise the model defaults apply.

`WaveSpeedVideoTool`:
- **model**: Model used for text-to-video generation. Default is `alibaba/wan-3.0/text-to-video`.
- **image_model**: Model used when an image is given. Default is `alibaba/wan-3.0/image-to-video`.
- **aspect_ratio**, **duration**, **resolution**: Optional. Sent only when set, otherwise the model defaults apply.

Both tools:
- **extra_params**: Additional model inputs sent with every request, for parameters of the chosen model that the tool does not expose directly.
- **timeout**: Maximum seconds to wait for a result. Default is 300 for images and 900 for videos.
- **poll_interval**: Seconds between result checks. Default is 2.

For example:

```python Code
from crewai_tools import WaveSpeedImageTool, WaveSpeedVideoTool

image_tool = WaveSpeedImageTool(aspect_ratio="16:9", resolution="2k")
video_tool = WaveSpeedVideoTool(duration=5, resolution="720p")

Agent(
    ...
    tools=[image_tool, video_tool]
)
```

Any model available on WaveSpeed AI can be used by passing its id as `model`. The inputs each model accepts are listed in the [WaveSpeed AI documentation](https://wavespeed.ai/docs).

## Error handling

The tools raise an error when `WAVESPEED_API_KEY` is not set, when the API rejects a request, when a prediction fails or is cancelled, or when no result arrives within `timeout`. A request is submitted only once per call and is never resubmitted automatically.
