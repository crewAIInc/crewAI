description: "Enrich companies, search company profiles, and discover similar companies."
---

## Setup

Install `crewai-tools` and set `COMPANYENRICH_API_KEY` to a key from your [CompanyEnrich dashboard](https://app.companyenrich.com/). You can also pass `api_key` when constructing each tool.

## Usage

```python
from crewai import Agent
from crewai_tools import (
    CompanyEnrichCompanyTool,
    CompanyEnrichSearchTool,
    CompanyEnrichSimilarTool,
)

tools = [
    CompanyEnrichCompanyTool(),
    CompanyEnrichSearchTool(),
    CompanyEnrichSimilarTool(),
]
agent = Agent(
    role="Company researcher",
    goal="Research companies using current company data",
    backstory="You research company profiles and matching accounts.",
    tools=tools,
)

# Direct calls also work; these consume CompanyEnrich credits.
profile = tools[0].run(domain="stripe.com")
companies = tools[1].run(semantic_query="B2B software companies", page_size=5)
lookalikes = tools[2].run(domains=["stripe.com"], page_size=5)
```

## Behavior

Each tool makes one request with a 30-second timeout (configurable with `timeout`). Search and similar-company tools return one page, including the original pagination metadata. `page` starts at 1; `page_size` defaults to 5 and accepts 1–100. Similar-company discovery accepts 1–10 domains. Search requires `page * page_size <= 10000`.

Enrichment costs 1 credit per call. Search costs 1 credit per returned company (minimum 1); similar-company discovery costs 5 credits per returned company (minimum 5). Calls are not automatically retried or paginated. HTTP errors, including invalid credentials (401), insufficient credits (402), and rate limits (429), are raised to the caller.

See the [CompanyEnrich API reference](https://docs.companyenrich.com/reference) for response fields and current pricing.
