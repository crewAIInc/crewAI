## Overview


The `WeaviateVectorSearchTool` is specifically crafted for conducting semantic searches within documents stored in a Weaviate vector database. This tool allows you to find semantically similar documents to a given query, leveraging the power of vector and keyword search for more accurate and contextually relevant search results.

[Weaviate](https://weaviate.io/) is a vector database that stores and queries vector embeddings, enabling semantic search capabilities.

## Installation

To incorporate this tool into your project, you need to install the Weaviate client:

```shell
uv add weaviate-client
```

## Steps to Get Started

To effectively use the `WeaviateVectorSearchTool`, follow these steps:

1. **Package Installation**: Confirm that the `crewai[tools]` and `weaviate-client` packages are installed in your Python environment.
2. **Weaviate Setup**: Set up a Weaviate Cloud cluster by following the [Weaviate documentation](https://weaviate.io/developers/wcs/manage-clusters/connect), or run Weaviate yourself (for example with Docker).
3. **API Keys**: For Weaviate Cloud, obtain your cluster URL and API key.
4. **OpenAI API Key (optional)**: If your collection vectorizes with OpenAI, set `OPENAI_API_KEY` in your environment. The tool forwards it to Weaviate. Collections that use another vectorizer don't need it.

## Example

The following example demonstrates how to initialize the tool and execute a search:

```python Code
from crewai_tools import WeaviateVectorSearchTool

# Initialize the tool
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    alpha=0.75,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)

@agent
def search_agent(self) -> Agent:
    '''
    This agent uses the WeaviateVectorSearchTool to search for 
    semantically similar documents in a Weaviate vector database.
    '''
    return Agent(
        config=self.agents_config["search_agent"],
        tools=[tool]
    )
```

## Parameters

The `WeaviateVectorSearchTool` accepts the following parameters:

- **collection_name**: Required. The name of the collection to search within.
- **weaviate_cluster_url**: Optional. The URL of a Weaviate Cloud cluster. When it is not set, the tool connects to a self-hosted Weaviate at `weaviate_host`.
- **weaviate_api_key**: Optional. The API key for the Weaviate cluster. Required with `weaviate_cluster_url`.
- **weaviate_host**: Optional. Host of a self-hosted Weaviate. Default is `localhost`.
- **weaviate_http_port** / **weaviate_grpc_port**: Optional. Ports of a self-hosted Weaviate. Defaults are `8080` and `50051`.
- **weaviate_secure**: Optional. Use HTTPS and TLS gRPC for a self-hosted Weaviate. Default is `False`.
- **headers**: Optional. Extra headers sent to Weaviate, such as API keys for model providers.
- **search_type**: Optional. `hybrid` (vector and keyword), `near_text` (vector only) or `bm25` (keyword only). Default is `hybrid`.
- **limit**: Optional. The number of results to return. Default is `3`.
- **alpha**: Optional. For `hybrid` search, controls the weighting between vector and keyword (BM25) search. alpha = 0 -> BM25 only, alpha = 1 -> vector search only. Default is `0.75`.
- **target_vector**: Optional. The named vector, or list of named vectors, to search in collections with more than one vector.
- **return_properties**: Optional. The properties to return for each result. Returns all properties by default.
- **filters**: Optional. A `weaviate.classes.query.Filter` applied to every search.
- **tenant**: Optional. The tenant to search in a multi-tenant collection.
- **create_collection_if_missing**: Optional. Create the collection with `vectorizer` and `generative_model` if it does not exist. Default is `False`.
- **vectorizer**: Optional. The vector configuration used when the tool creates the collection. Default is `Configure.Vectors.text2vec_openai(model="text-embedding-3-small")`.
- **generative_model**: Optional. The generative model used when the tool creates the collection. Default is OpenAI's `gpt-4o`.

## Self-hosted Weaviate

Leave out `weaviate_cluster_url` to connect to a Weaviate you run yourself:

```python Code
from crewai_tools import WeaviateVectorSearchTool

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    weaviate_host="localhost",
    weaviate_http_port=8080,
    weaviate_grpc_port=50051,
)
```

Set `weaviate_secure=True` when your Weaviate is served over HTTPS. Pass `weaviate_api_key` if it requires authentication.

## Search Options

Choose the type of search, the named vector to search and the properties to return, and filter the results:

```python Code
from crewai_tools import WeaviateVectorSearchTool
from weaviate.classes.query import Filter

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    search_type="near_text",
    target_vector="body_vector",
    return_properties=["title", "body"],
    filters=Filter.by_property("year").greater_than(2020),
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

## Multi-tenancy

For a [multi-tenant collection](https://docs.weaviate.io/weaviate/manage-collections/multi-tenancy), set `tenant` to search only that tenant's data:

```python Code
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    tenant="customer_a",
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

The tenant is set when you create the tool, not by the agent, so an agent cannot read another tenant's data.

## Creating the Collection and Quantization

By default, the tool only searches existing collections. Set `create_collection_if_missing=True` to have it create the collection on first use. The tool uses `vectorizer` and `generative_model` for the new collection, makes it multi-tenant when `tenant` is set, and creates that tenant.

`vectorizer` accepts any `Configure.Vectors` configuration, so you can also choose the [vector quantization](https://docs.weaviate.io/weaviate/configuration/compression) here. This example uses local models served by Ollama and scalar quantization:

```python Code
from crewai_tools import WeaviateVectorSearchTool
from weaviate.classes.config import Configure

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    create_collection_if_missing=True,
    vectorizer=Configure.Vectors.text2vec_ollama(
        api_endpoint="http://host.docker.internal:11434",
        model="nomic-embed-text",
        quantizer=Configure.VectorIndex.Quantizer.sq(),
    ),
    generative_model=Configure.Generative.ollama(
        api_endpoint="http://host.docker.internal:11434",
        model="llama3.2",
    ),
)
```

The other quantizers are `Configure.VectorIndex.Quantizer.rq()`, `.bq()` and `.pq()`.

## Preloading Documents

You can preload your Weaviate database with documents before using the tool:

```python Code
import os
from crewai_tools import WeaviateVectorSearchTool
import weaviate
from weaviate.classes.config import Configure
from weaviate.classes.init import Auth

# Connect to Weaviate
client = weaviate.connect_to_weaviate_cloud(
    cluster_url="https://your-weaviate-cluster-url.com",
    auth_credentials=Auth.api_key("your-weaviate-api-key"),
    headers={"X-OpenAI-Api-Key": "your-openai-api-key"}
)

# Get or create collection
if client.collections.exists("example_collections"):
    test_docs = client.collections.get("example_collections")
else:
    test_docs = client.collections.create(
        name="example_collections",
        vector_config=Configure.Vectors.text2vec_openai(model="text-embedding-3-small"),
        generative_config=Configure.Generative.openai(model="gpt-4o"),
    )

# Load documents
docs_to_load = os.listdir("knowledge")
with test_docs.batch.dynamic() as batch:
    for d in docs_to_load:
        with open(os.path.join("knowledge", d), "r") as f:
            content = f.read()
        batch.add_object(
            {
                "content": content,
                "year": d.split("_")[0],
            }
        )

# Initialize the tool
tool = WeaviateVectorSearchTool(
    collection_name='example_collections', 
    limit=3,
    alpha=0.75,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

## Agent Integration Example

Here's how to integrate the `WeaviateVectorSearchTool` with a CrewAI agent:

```python Code
from crewai import Agent
from crewai_tools import WeaviateVectorSearchTool

# Initialize the tool
weaviate_tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    alpha=0.75,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)

# Create an agent with the tool
rag_agent = Agent(
    name="rag_agent",
    role="You are a helpful assistant that can answer questions with the help of the WeaviateVectorSearchTool.",
    llm="gpt-4o-mini",
    tools=[weaviate_tool],
)
```

## Conclusion

The `WeaviateVectorSearchTool` provides a powerful way to search for semantically similar documents in a Weaviate vector database. By leveraging vector embeddings, it enables more accurate and contextually relevant search results compared to traditional keyword-based searches. This tool is particularly useful for applications that require finding information based on meaning rather than exact matches.
