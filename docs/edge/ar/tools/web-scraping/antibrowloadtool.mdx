# `AntibrowLoadTool`

## الوصف

يفتح `AntibrowLoadTool` صفحة في ملف تعريف من [AntiBrow](https://antibrow.com) ويعيد نصها المرئي. الفرق عن أدوات الاستخلاص الأخرى هنا هو مكان حفظ الحالة: الوحدة هي *ملف التعريف*، لذا تبقى الكوكيز والتخزين وبصمة المتصفح المطبَّقة على مستوى المحرك وبروكسي الملف نفسه محفوظة بين التشغيلات. الصفحة التي تحتاج تسجيل دخول تُفتح وأنت مسجَّل بالفعل، بدلاً من البدء من الصفر في متصفح جديد.

الميزات الأساسية:
- هوية دائمة - اسم الملف نفسه يحصل دائماً على البصمة والكوكيز والتخزين نفسها
- بروكسي واحد لكل ملف تعريف - يُعالج داخل محرك المتصفح، فلا شيء يُحمَّل كامتداد
- Playwright قياسي في الأسفل - يعيد الـ SDK كائنات Playwright عادية
- تشغيل محلي - المتصفح يعمل على جهازك، فلا توجد ساعات متصفح تُشترى

## التثبيت

لاستخدام هذه الأداة، ثبّت SDK الخاص بـ AntiBrow:

```shell
uv add antibrow
```

## خطوات البدء

1. **التسجيل**: اذهب إلى [AntiBrow](https://antibrow.com/dashboard) للتسجيل وإنشاء API key.
2. **API Key**: عيّن متغير البيئة `ANTIBROW_API_KEY` أو مرّر المفتاح مباشرة إلى مُنشئ الأداة.
3. **تثبيت SDK**: ثبّت SDK الخاص بـ AntiBrow بالأمر أعلاه. يُنزَّل محرك المتصفح عند أول تشغيل ويُحفظ في الكاش.

## مثال

```python Code
from crewai_tools import AntibrowLoadTool
from crewai import Agent

# The profile name is the identity. Reuse it and the session is still there.
tool = AntibrowLoadTool(profile="research-01")  # api_key read from the environment

@agent
def web_researcher(self) -> Agent:
    '''
    This agent reads pages through a persistent AntiBrow profile, so pages
    that need a login keep working across runs.
    '''
    return Agent(
        config=self.agents_config["web_researcher"],
        tools=[tool]
    )
```

## المعاملات

تقبل الأداة الوسائط التالية عند التشغيل:

- **url**: مطلوب. الرابط الذي سيتم تحميله.
- **selector**: اختياري. محدِّد CSS لقراءته بدلاً من الصفحة كاملة، مثل `main` أو `h1`.

والخيارات التالية في المُنشئ:

- **api_key**: اختياري. مفتاح AntiBrow الخاص بك. يرجع إلى `ANTIBROW_API_KEY` عند عدم تمريره.
- **profile**: اختياري. اسم ملف التعريف، وقيمته الافتراضية `agent`. غير محدود ومجاني محلياً.
- **proxy**: اختياري. رابط البروكسي لهذا الملف (`http` أو `https` أو `socks5`، مع بيانات الدخول في الرابط).
- **temporary**: اختياري. يتخلص من ملف التعريف عند إغلاق المتصفح. القيمة الافتراضية `False`.
- **headless**: اختياري. يخفي نافذة المتصفح. القيمة الافتراضية `False`.
- **keep_open**: اختياري. يعيد استخدام متصفح واحد بين النداءات، ليبقى تسجيل الدخول قائماً بين خطوات الـ crew. القيمة الافتراضية `True`.
- **max_content_length**: اختياري. يقتطع نص الصفحة عند هذا العدد من الأحرف. القيمة الافتراضية `100000`.

## ملاحظات

نادِ `tool.close()` عند انتهاء الـ crew. المتصفح المتروك هو متصفح كامل لا يزال يعمل.

الـ agent اللذان يجب ألا يتشاركا الهوية يحتاجان إلى اسمَي ملفَي تعريف، لا إلى تبويبين. وعدد ما يمكن تشغيله في وقت واحد هو حد التزامن في خطتك.

الهوية الدائمة تُزيل الآثار الناتجة عن البدء من الصفر في كل تشغيل: ملف تعريف جديد، وبصمة أتمتة افتراضية، وعنوان IP الخاص بك. وهي لا تضمن أن موقعاً معيناً سيقبل جلسة مؤتمتة.
