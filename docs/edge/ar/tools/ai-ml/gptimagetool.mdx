تتولى Ace Data Cloud صيانة هذه الحزمة لاستخدام GPT Image مع CrewAI.

## التثبيت

```bash
uv add crewai-gpt-image==0.1.0
```

أنشئ [رمز API للتطبيق](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=gptimagecrewai_docs_api_key) يتيح الوصول إلى GPT Image واحفظه في متغير البيئة `ACEDATACLOUD_API_KEY`. راجع [الأسعار الحالية](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=gptimagecrewai_docs_pricing) قبل توليد الوسائط.

## الاستخدام

يستخدم GPT Image حقول size/quality/n وخيارات الخلفية والتنسيق. المسار /openai/images/generations مع response_format=url. ليس DallETool أو Nano Banana. النتيجة data[].url؛ تحرير multipart غير مشمول.

أضف `GPTImageGenerateImageTool()` و`GPTImageRetrieveTaskTool()` إلى قائمة `tools` الخاصة بالوكيل. تُعيد أداة التوليد معرّف المهمة. لمتابعة تقدمها، استعلم عن المعرّف نفسه باستخدام المفتاح الذي أرسل المهمة.

```python
from gpt_image_crewai import GPTImageRetrieveTaskTool

result = GPTImageRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```
