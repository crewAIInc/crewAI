تتولى Ace Data Cloud صيانة هذه الحزمة لاستخدام Nano Banana مع CrewAI.

## التثبيت

```bash
uv add crewai-nano-banana==0.1.0
```

أنشئ [رمز API للتطبيق](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=nanobananacrewai_docs_api_key) يتيح الوصول إلى Nano Banana واحفظه في متغير البيئة `ACEDATACLOUD_API_KEY`. راجع [الأسعار الحالية](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=nanobananacrewai_docs_pricing) قبل توليد الوسائط.

## الاستخدام

يستخدم /nano-banana/images أفعال generate/edit وcount1..4 وaspect_ratio ودقة1K/2K/4K وimage_urls؛ edit يتطلب المراجع. لا يستخدم size/quality/n. النتيجة data[].image_url.

أضف `NanoBananaGenerateImageTool()` و`NanoBananaRetrieveTaskTool()` إلى قائمة `tools` الخاصة بالوكيل. تُعيد أداة التوليد معرّف المهمة. لمتابعة تقدمها، استعلم عن المعرّف نفسه باستخدام المفتاح الذي أرسل المهمة.

```python
from nano_banana_crewai import NanoBananaRetrieveTaskTool

result = NanoBananaRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```
