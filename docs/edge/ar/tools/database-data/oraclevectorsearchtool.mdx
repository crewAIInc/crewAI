## نظرة عامة

تبحث `OracleVectorSearchTool` في المستندات المخزنة في Oracle Database باستخدام Oracle AI Vector Search. تدعم مرشحات البيانات الوصفية JSON، وحدود النتائج لكل استعلام، وحدود المسافة القصوى، وفهارس HNSW أو IVF.

## التثبيت والمتطلبات

استخدم Oracle Database 23ai أو أحدث مع إتاحة AI Vector Search. ثبّت الإضافة الخاصة بـ Oracle:

```bash
uv add 'crewai-tools[oracledb]'
```

عيّن `ORACLE_DB_USERNAME` و`ORACLE_DB_SECRET` و`ORACLE_DB_DSN` للأمثلة أدناه. تقرأ الأمثلة هذه الأسماء صراحةً.

استورد نموذج تضمين إلى Oracle Database قبل تشغيل هذا المثال، وعيّن `ORACLE_EMBEDDING_MODEL` إلى اسم النموذج و`ORACLE_EMBEDDING_DIMENSIONS` إلى بُعد مخرجاته. تثبيت `oracledb` لا يثبت نموذج تضمين. يحتاج الحساب إلى صلاحية استخدام `DBMS_VECTOR_CHAIN.UTL_TO_EMBEDDINGS` والنموذج المختار. يجب ألا يتجاوز كل مستند يمرّر إلى مزود Oracle عدد 4000 حرف.

## الاستخدام الأساسي

يولّد هذا المثال التضمينات في Oracle Database، وينشئ جدولاً، ويدرج مستندين، ويبحث فيهما. يجب أن يطابق نموذج التضمين وبُعد المتجه المتجهات المخزنة مسبقاً في أي جدول موجود.

```python
import os

import oracledb
from crewai.rag.embeddings.factory import build_embedder
from crewai_tools import (
    OracleVectorSearchConfig,
    OracleVectorSearchQueryConfig,
    OracleVectorSearchTool,
)

connection = oracledb.connect(
    user=os.environ["ORACLE_DB_USERNAME"],
    password=os.environ["ORACLE_DB_SECRET"],
    dsn=os.environ["ORACLE_DB_DSN"],
)
oracle_embedder = build_embedder({
    "provider": "oracle",
    "config": {
        "conn": connection,
        "embedding_params": {
            "provider": "database",
            "model": os.environ["ORACLE_EMBEDDING_MODEL"],
        },
    },
})


def embed_text(text: str) -> list[float]:
    if not isinstance(text, str):
        raise TypeError("embed_text expects a single string")
    return oracle_embedder([text])[0].tolist()


tool = OracleVectorSearchTool(
    oracle_config=OracleVectorSearchConfig(
        table_name="CREWAI_DOCS",
        distance_strategy="COSINE",
        limit=3,
    ),
    query_config=OracleVectorSearchQueryConfig(filter={"source": "docs"}),
    client=connection,
    embedding_function=embed_text,
    dimensions=int(os.environ["ORACLE_EMBEDDING_DIMENSIONS"]),
)

tool.create_table()
tool.add_texts(
    [
        "CrewAI agents can search documents in Oracle Database.",
        "Oracle AI Vector Search supports semantic similarity queries.",
    ],
    metadatas=[
        {"source": "docs", "tags": ["oracle", "crewai"]},
        {"source": "docs", "tags": ["oracle", "search"]},
    ],
)

results = tool.run(query="How can agents search Oracle documents?")
print(results)
```

يجب أن يحتوي الجدول على الأعمدة `id` و`text` و`metadata` (نوع Oracle `JSON` الأصلي) و`embedding` (`VECTOR`). تنشئ `create_table()` الأعمدة `id VARCHAR2(64) PRIMARY KEY` و`text CLOB` و`metadata JSON` و`embedding VECTOR(dimensions, FLOAT32)`. يحتاج الحساب إلى الوصول إلى الجدول وصلاحيات إنشاء الجداول أو الفهارس التي يستخدمها.

تنفذ `create_table()` وإنشاء الفهارس أوامر Oracle DDL التي تعتمد المعاملة ضمنياً. تعتمد استدعاءات `add_texts()` الناجحة المعاملة على الاتصال. عند فشل إدراج، تُسترجع الدفعة إلى savepoint، مع الحفاظ على العمل المعلّق السابق إذا كان الجدول موجوداً مسبقاً.

## مرشحات البيانات الوصفية والمسافات

مرّر المرشحات المركّبة كسلسلة JSON عبر `filters`. تُجمع مرشحات `query_config` ومرشحات استدعاء البحث باستخدام AND.

```python
import json

results = tool.run(
    query="Oracle semantic search",
    filters=json.dumps({"tags": {"$in": ["search"]}}),
    limit=2,
    score_threshold=0.6,
)
```

تشمل المعاملات `$eq` و`$ne` و`$gt` و`$gte` و`$lt` و`$lte` و`$between` و`$in` و`$nin` و`$all` و`$exists` و`$not`؛ ويمكن جمعها باستخدام `$and` أو `$or` أو `$nor`. يجب ألا تكون القوائم المنطقية وكائنات المرشحات المتداخلة فارغة. تتطلب `$in` و`$nin` و`$all` قوائم غير فارغة. تفحص `$in` و`$nin` القيم المفردة أو عناصر المصفوفة، بينما تتطلب `$all` كل القيم المطلوبة. تمثّل النقاط أعضاء متداخلين، وتمثّل `[*]` محرفاً عاماً للمصفوفة، وتُقتبس تلقائياً أسماء الأعضاء التي تحتوي على مسافات. للمساواة البسيطة بين القيم المفردة، مرّر `filter_by` و`filter_value` معاً.

تمثّل `score_threshold` المسافة القصوى: تبقى النتيجة عندما تكون `distance <= score_threshold`. الاستراتيجيات هي `COSINE` و`EUCLIDEAN` و`DOT`. تعيد `DOT` سالب الضرب الداخلي، لذا تكون الحدود السالبة صالحة. يجب أن تكون حدود النتائج أعداداً صحيحة موجبة. تُستبعد الصفوف ذات التضمينات null.

## الفهارس المتجهية

أنشئ الفهرس بعد تحميل المستندات. النوع الافتراضي هو HNSW، وIVF بديل متاح. يجب أن تدعم موارد قاعدة البيانات وصلاحياتها النوع المختار.

```python
tool.create_vector_index(idx_type="HNSW", params={"accuracy": 90})

# An alternative to HNSW:
# tool.create_vector_index(index_name="CREWAI_DOCS_IVF", idx_type="IVF")

print(tool.vector_index_exists(idx_type="HNSW"))
```

إذا لم تحدد `index_name`، تُولّد الأسماء من اسم الجدول ونوع الفهرس. استخدم `vector_index_exists(idx_type="IVF")` عند التحقق من فهرس IVF. تُدعم أسماء الجداول والفهارس المؤهلة باسم المخطط، وتُحفظ حالة الأحرف في المعرّفات.

## اتصالات Oracle

يستخدم المثال [مزود التضمينات Oracle](/edge/ar/concepts/memory) مع اتصال يديره المستدعي. أبقِ الاتصال مفتوحاً لأمثلة البحث والفهرسة أعلاه، ثم استدعِ `connection.close()` عند الانتهاء.

تقبل `client` أيضاً `oracledb.ConnectionPool` يديره المستدعي. تحصل الأداة على اتصال لكل عملية في قاعدة البيانات. أبقِ الاتصالات أو المجموعات مفتوحة أثناء الاستخدام وأغلقها عند الانتهاء. تمرّر `connection_kwargs` الخيارات الإضافية، مثل إعداد wallet، إلى `oracledb.connect()` عندما تنشئ الأداة اتصالها.

## الإعداد

| الوسيط | الغرض |
| --- | --- |
| `oracle_config` | إعدادات الاتصال والبحث. `table_name` مطلوب؛ وفّر بيانات الاتصال عند عدم تمرير `client`. تشمل الحقول الأخرى `connection_kwargs` و`limit` و`score_threshold` و`distance_strategy` و`index_name`. |
| `query_config` | قيم افتراضية اختيارية لـ `filter` و`limit` و`score_threshold`. تتجاوز الحدود لكل استدعاء القيم الافتراضية. |
| `client` | اتصال Oracle أو مجموعة اتصالات موجودة. |
| `embedding_function` | دالة لتضمين نص واحد؛ وفّر دالة تضمين Oracle الموضحة أعلاه. |
| `dimensions` | بُعد المتجه لإنشاء الجداول؛ اضبطه على بُعد مخرجات نموذج Oracle. |

## النتائج والأخطاء

تعيد `run()` سلسلة JSON تحتوي على قائمة نتائج. تحتوي كل نتيجة على `context` و`metadata` و`distance` و`score`. تساوي `score` حالياً المسافة الخام؛ وليست درجة تشابه مطبّعة. يعيد البحث الناجح دون تطابقات `"[]"`. تُسجّل أخطاء البحث وتعيد سلسلة فارغة (`""`)؛ راجع السجلات قبل اعتبار السلسلة الفارغة دليلاً على عدم وجود نتائج.
