## نظرة عامة

صُممت `WeaviateVectorSearchTool` خصيصاً لإجراء عمليات بحث دلالي داخل المستندات المخزنة في قاعدة بيانات Weaviate المتجهية. تتيح لك هذه الأداة العثور على مستندات متشابهة دلالياً لاستعلام معين، من خلال الاستفادة من قوة البحث المتجهي والبحث بالكلمات المفتاحية للحصول على نتائج بحث أكثر دقة وذات صلة بالسياق.

[Weaviate](https://weaviate.io/) هي قاعدة بيانات متجهية تخزن وتستعلم عن التضمينات المتجهية، مما يتيح إمكانيات البحث الدلالي.

## التثبيت

لدمج هذه الأداة في مشروعك، تحتاج إلى تثبيت عميل Weaviate:

```shell
uv add weaviate-client
```

## خطوات البدء

لاستخدام `WeaviateVectorSearchTool` بفعالية، اتبع هذه الخطوات:

1. **تثبيت الحزمة**: تأكد من تثبيت حزمتي `crewai[tools]` و `weaviate-client` في بيئة Python الخاصة بك.
2. **إعداد Weaviate**: قم بإعداد مجموعة Weaviate Cloud باتباع [وثائق Weaviate](https://weaviate.io/developers/wcs/manage-clusters/connect)، أو شغّل Weaviate بنفسك (على سبيل المثال باستخدام Docker).
3. **مفاتيح API**: بالنسبة لـ Weaviate Cloud، احصل على عنوان URL للمجموعة ومفتاح API.
4. **مفتاح OpenAI API (اختياري)**: إذا كانت مجموعتك تستخدم OpenAI للتحويل المتجهي، فعيّن `OPENAI_API_KEY` في بيئتك. تمرّر الأداة هذا المفتاح إلى Weaviate. المجموعات التي تستخدم محوّلاً متجهياً آخر لا تحتاج إليه.

## مثال

يوضح المثال التالي كيفية تهيئة الأداة وتنفيذ بحث:

```python Code
from crewai_tools import WeaviateVectorSearchTool

# Initialize the tool
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    alpha=0.75,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)

@agent
def search_agent(self) -> Agent:
    '''
    This agent uses the WeaviateVectorSearchTool to search for
    semantically similar documents in a Weaviate vector database.
    '''
    return Agent(
        config=self.agents_config["search_agent"],
        tools=[tool]
    )
```

## المعاملات

تقبل `WeaviateVectorSearchTool` المعاملات التالية:

- **collection_name**: مطلوب. اسم المجموعة المراد البحث فيها.
- **weaviate_cluster_url**: اختياري. عنوان URL لمجموعة Weaviate Cloud. عندما لا يُحدد، تتصل الأداة بـ Weaviate مستضاف ذاتياً على `weaviate_host`.
- **weaviate_api_key**: اختياري. مفتاح API لمجموعة Weaviate. مطلوب مع `weaviate_cluster_url`.
- **weaviate_host**: اختياري. مضيف Weaviate المستضاف ذاتياً. الافتراضي هو `localhost`.
- **weaviate_http_port** / **weaviate_grpc_port**: اختياري. منافذ Weaviate المستضاف ذاتياً. القيم الافتراضية هي `8080` و `50051`.
- **weaviate_secure**: اختياري. استخدام HTTPS و gRPC عبر TLS لـ Weaviate المستضاف ذاتياً. الافتراضي هو `False`.
- **headers**: اختياري. ترويسات إضافية تُرسل إلى Weaviate، مثل مفاتيح API لمزوّدي النماذج.
- **search_type**: اختياري. `hybrid` (متجهي وبالكلمات المفتاحية)، أو `near_text` (متجهي فقط)، أو `bm25` (بالكلمات المفتاحية فقط). الافتراضي هو `hybrid`.
- **limit**: اختياري. عدد النتائج المُرجعة. الافتراضي هو `3`.
- **alpha**: اختياري. في البحث `hybrid`، يتحكم في الترجيح بين البحث المتجهي والبحث بالكلمات المفتاحية (BM25). alpha = 0 -> BM25 فقط، alpha = 1 -> بحث متجهي فقط. الافتراضي هو `0.75`.
- **target_vector**: اختياري. المتجه المسمّى، أو قائمة المتجهات المسمّاة، المراد البحث فيها في المجموعات التي تحتوي على أكثر من متجه.
- **return_properties**: اختياري. الخصائص المُرجعة لكل نتيجة. تُرجع جميع الخصائص افتراضياً.
- **filters**: اختياري. مرشّح `weaviate.classes.query.Filter` يُطبّق على كل عملية بحث.
- **tenant**: اختياري. المستأجر المراد البحث فيه في مجموعة متعددة المستأجرين.
- **create_collection_if_missing**: اختياري. إنشاء المجموعة باستخدام `vectorizer` و `generative_model` إذا لم تكن موجودة. الافتراضي هو `False`.
- **vectorizer**: اختياري. تكوين المتجهات المستخدم عندما تنشئ الأداة المجموعة. الافتراضي هو `Configure.Vectors.text2vec_openai(model="text-embedding-3-small")`.
- **generative_model**: اختياري. النموذج التوليدي المستخدم عندما تنشئ الأداة المجموعة. الافتراضي هو `gpt-4o` من OpenAI.

## Weaviate المستضاف ذاتياً

احذف `weaviate_cluster_url` للاتصال بـ Weaviate تشغّله بنفسك:

```python Code
from crewai_tools import WeaviateVectorSearchTool

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    weaviate_host="localhost",
    weaviate_http_port=8080,
    weaviate_grpc_port=50051,
)
```

عيّن `weaviate_secure=True` عندما يُقدَّم Weaviate الخاص بك عبر HTTPS. مرّر `weaviate_api_key` إذا كان يتطلب المصادقة.

## خيارات البحث

اختر نوع البحث، والمتجه المسمّى المراد البحث فيه، والخصائص المُرجعة، وقم بترشيح النتائج:

```python Code
from crewai_tools import WeaviateVectorSearchTool
from weaviate.classes.query import Filter

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    search_type="near_text",
    target_vector="body_vector",
    return_properties=["title", "body"],
    filters=Filter.by_property("year").greater_than(2020),
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

## تعدد المستأجرين

بالنسبة لـ [مجموعة متعددة المستأجرين](https://docs.weaviate.io/weaviate/manage-collections/multi-tenancy)، عيّن `tenant` للبحث في بيانات ذلك المستأجر فقط:

```python Code
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    tenant="customer_a",
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

يُحدَّد المستأجر عند إنشاء الأداة، وليس بواسطة الوكيل، لذلك لا يمكن للوكيل قراءة بيانات مستأجر آخر.

## إنشاء المجموعة والتكميم

افتراضياً، تبحث الأداة في المجموعات الموجودة فقط. عيّن `create_collection_if_missing=True` لجعلها تنشئ المجموعة عند أول استخدام. تستخدم الأداة `vectorizer` و `generative_model` للمجموعة الجديدة، وتجعلها متعددة المستأجرين عند تعيين `tenant`، وتنشئ ذلك المستأجر.

يقبل `vectorizer` أي تكوين `Configure.Vectors`، لذا يمكنك أيضاً اختيار [تكميم المتجهات](https://docs.weaviate.io/weaviate/configuration/compression) هنا. يستخدم هذا المثال نماذج محلية يقدّمها Ollama والتكميم القياسي (scalar quantization):

```python Code
from crewai_tools import WeaviateVectorSearchTool
from weaviate.classes.config import Configure

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    create_collection_if_missing=True,
    vectorizer=Configure.Vectors.text2vec_ollama(
        api_endpoint="http://host.docker.internal:11434",
        model="nomic-embed-text",
        quantizer=Configure.VectorIndex.Quantizer.sq(),
    ),
    generative_model=Configure.Generative.ollama(
        api_endpoint="http://host.docker.internal:11434",
        model="llama3.2",
    ),
)
```

أدوات التكميم الأخرى هي `Configure.VectorIndex.Quantizer.rq()` و `.bq()` و `.pq()`.

## تحميل المستندات مسبقاً

يمكنك تحميل قاعدة بيانات Weaviate بالمستندات مسبقاً قبل استخدام الأداة:

```python Code
import os
from crewai_tools import WeaviateVectorSearchTool
import weaviate
from weaviate.classes.config import Configure
from weaviate.classes.init import Auth

# Connect to Weaviate
client = weaviate.connect_to_weaviate_cloud(
    cluster_url="https://your-weaviate-cluster-url.com",
    auth_credentials=Auth.api_key("your-weaviate-api-key"),
    headers={"X-OpenAI-Api-Key": "your-openai-api-key"}
)

# Get or create collection
if client.collections.exists("example_collections"):
    test_docs = client.collections.get("example_collections")
else:
    test_docs = client.collections.create(
        name="example_collections",
        vector_config=Configure.Vectors.text2vec_openai(model="text-embedding-3-small"),
        generative_config=Configure.Generative.openai(model="gpt-4o"),
    )

# Load documents
docs_to_load = os.listdir("knowledge")
with test_docs.batch.dynamic() as batch:
    for d in docs_to_load:
        with open(os.path.join("knowledge", d), "r") as f:
            content = f.read()
        batch.add_object(
            {
                "content": content,
                "year": d.split("_")[0],
            }
        )

# Initialize the tool
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    alpha=0.75,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

## مثال على التكامل مع الوكيل

إليك كيفية دمج `WeaviateVectorSearchTool` مع وكيل CrewAI:

```python Code
from crewai import Agent
from crewai_tools import WeaviateVectorSearchTool

# Initialize the tool
weaviate_tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    alpha=0.75,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)

# Create an agent with the tool
rag_agent = Agent(
    name="rag_agent",
    role="You are a helpful assistant that can answer questions with the help of the WeaviateVectorSearchTool.",
    llm="gpt-4o-mini",
    tools=[weaviate_tool],
)
```

## الخلاصة

توفر `WeaviateVectorSearchTool` طريقة قوية للبحث عن مستندات متشابهة دلالياً في قاعدة بيانات Weaviate المتجهية. من خلال الاستفادة من التضمينات المتجهية، تتيح نتائج بحث أكثر دقة وذات صلة بالسياق مقارنة بعمليات البحث التقليدية القائمة على الكلمات المفتاحية. هذه الأداة مفيدة بشكل خاص للتطبيقات التي تتطلب العثور على المعلومات بناءً على المعنى بدلاً من التطابق الحرفي.
