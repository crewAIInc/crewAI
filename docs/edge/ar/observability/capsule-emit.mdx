# نظرة عامة على Agent Action Capsule

يسجّل [capsule-emit](https://github.com/action-state-group/capsule-emit) كل استدعاء أداة في تشغيل الطاقم كسلسلة من **Agent Action Capsules**: كبسولة *مخططة* تُختم عند بدء الاستدعاء، ثم كبسولة *مؤكَّدة* (أو *فاشلة*) تُختم عند انتهائه وتُربط بالمخططة عبر معرّف الكبسولة. الكبسولات أدلة تدقيق وامتثال لما فعله الطاقم فعلياً — مكمّلة للتتبع.

طبقتا تحقق، متمايزتان عمداً:

- **دون اتصال، `verify()`** تفحص البنية والعنونة بالمحتوى (كل بصمة يُعاد حسابها من محتوى السجل نفسه) واتساق السلسلة — دون خدمة ودون بيانات اعتماد.
- **إثبات العبث تجاه طرف خارجي** يأتي من خطوة الترسيخ: تُسجَّل بصمات الكبسولات في سجل شفافية SCITT، وإيصال السجل هو ما يجعل التعديل اللاحق ظاهراً لطرف خارج بيئتك. تُشغِّل البداية السريعة هذه الخطوة على خدمة محلية بديلة ليبقى العرض محكماً؛ الترسيخ الإنتاجي يشير إلى سجل حقيقي.

### الميزات

- **مستمع واحد، كل استدعاء أداة**: سجّل `CapsuleEventListener()` مرة واحدة عبر آلية `BaseEventListener` القياسية في CrewAI — دون تغييرات في كود الأدوات.
- **سلاسل مخطط ← مؤكَّد**: تُختم كبسولة مخططة عند بدء استدعاء الأداة؛ وعند انتهائه تُختم كبسولة مؤكَّدة ثانية وتُربط بها (`prior_capsule_id`)؛ الأخطاء تختم كبسولة تأثير فاشل مربوطة.
- **خصوصية بالبصمات فقط**: تُلتزم مدخلات/مخرجات الأدوات كبصمات SHA-256 — المحتوى الخام يبقى محلياً؛ البصمات فقط تُرسَّخ.
- **فحوص اتساق دون اتصال**: تعيد `verify()` فحص البنية والعنونة بالمحتوى وروابط السلسلة من السجل وحده.
- **إثبات عبث مُرسَّخ**: تسجيل بالبصمات فقط في سجل شفافية SCITT؛ الإيصال هو الخطوة الحاملة لإثبات العبث المستقل.
- **آمن للطاقم بالتصميم**: يحترم المستمع `is_replaying()` ولا يرفع استثناءات في تشغيل الطاقم؛ تعذُّر الوصول إلى المرساة لا يمكن أن يكسر الطاقم.

## تعليمات الإعداد

<Steps>
    <Step title="ثبّت capsule-emit مع إضافة CrewAI">
      ```shell
      pip install "capsule-emit[crewai]"
      ```
    </Step>
    <Step title="سجّل المستمع">
      ```python
      from capsule_emit.adapters.crewai_listener import CapsuleEventListener

      # Register once, before kickoff — every tool call in the crew seals a capsule.
      listener = CapsuleEventListener(operator="acme-crew", developer="platform-team")
      ```
    </Step>
    <Step title="شغّل طاقمك كالمعتاد">
      ```python
      result = crew.kickoff()
      ```
      كل استدعاء أداة ينتج الآن سجلات مختومة في السجل المحلي (`ledger.jsonl` افتراضياً)، مع ترسيخ البصمات في خدمة شفافية SCITT المهيأة.
    </Step>
    <Step title="افحص الأدلة">
      ```python
      import json
      from agent_action_capsule import verify_store

      rows = [json.loads(line) for line in open("ledger.jsonl") if line.strip()]
      if not rows:
          raise SystemExit("empty ledger — nothing to verify")
      results = verify_store([row.get("capsule", row) for row in rows])
      ok = all(r.ok for r in results)
      print(f"{len(rows)} capsules, verify: {'ALL OK' if ok else 'FAILURES'}")
      ```
    </Step>
</Steps>

## ما الذي يُسجَّل

| الحقل | المحتوى |
|---|---|
| `action_id` / اسم الأداة | أي استدعاء أداة تسجله هذه الكبسولة |
| بصمات المدخلات / المخرجات | التزامات SHA-256 — المحتوى الخام لا يغادر بيئتك أبداً |
| `effect` | `planned` أو `executed` أو `confirmed` أو `errored` |
| سلسلة `confirms` | الكبسولة المنفَّذة تستشهد بالكبسولة المخططة بعنوان المحتوى |
| إيصال الترسيخ | تسجيل بالبصمات فقط في سجل شفافية SCITT (اختياري، مفعَّل افتراضياً) |

تنسيق السجل مواصفة مفتوحة (`draft-mih-scitt-agent-action-capsule`، مسودة إنترنت فردية لدى IETF) مع تنفيذ مرجعي برخصة Apache-2.0.
