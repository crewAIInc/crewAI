# نظرة عامة على Agent Action Capsule

يسجّل [capsule-emit](https://github.com/action-state-group/capsule-emit) كل استدعاء أداة في تشغيل الطاقم كسلسلة من **Agent Action Capsules**: كبسولة *مخططة* تُختم عند بدء الاستدعاء، ثم كبسولة *مؤكَّدة* (أو *فاشلة*) تُختم عند انتهائه وتُربط بالمخططة عبر معرّف الكبسولة. الكبسولات أدلة تدقيق وامتثال لما فعله الطاقم فعلياً — مكمّلة للتتبع.

طبقتا تحقق، متمايزتان عمداً:

- **التحقق دون اتصال** يفحص البنية والعنونة بالمحتوى (كل بصمة يُعاد حسابها من محتوى السجل نفسه) واتساق السلسلة وتوقيع المنتِج على كل سجل — دون خدمة ودون بيانات اعتماد. يثبت التوقيع أن المفتاح المذكور في السجل وقّعه، لا هوية حامل ذلك المفتاح: التوقيع ومعرّف المفتاح يقعان خارج البصمة، لذا فإن سجلاً أُعيد توقيعه بمفتاح جديد يجتاز التحقق أيضاً.
- **إثبات العبث تجاه طرف خارجي** يأتي من تدفق نقاط التفتيش/الشاهد المفعَّل افتراضياً (انظر الجدول أدناه). كل نقطة تفتيش يقبلها الشاهد تمنح طرفاً خارجياً مرجعاً يطابق عليه السجل، بقدر ما يثق ذلك الطرف في أن الشاهد مستقل عنك. السجلات المختومة بعد آخر نقطة تفتيش مقبولة لم تُلتزم بعد خارج بيئتك؛ والتشغيل الذي يختم أقل من 100 سجل، كلها خلال 900 ثانية، ينتهي دون نشر أي نقطة. أما المرساة القديمة لكل عملية ختم عبر SCITT فهي قناة قديمة، معطَّلة افتراضياً.

### الميزات

- **مستمع واحد، كل استدعاء أداة**: سجّل `CapsuleEventListener()` مرة واحدة عبر آلية `BaseEventListener` القياسية في CrewAI — دون تغييرات في كود الأدوات.
- **سلاسل مخطط ← مؤكَّد**: تُختم كبسولة مخططة عند بدء استدعاء الأداة؛ وعند انتهائه تُختم كبسولة مؤكَّدة ثانية وتُربط بها (`prior_capsule_id`)؛ الأخطاء تختم كبسولة تأثير فاشل مربوطة.
- **خصوصية بالبصمات فقط**: تُلتزم مدخلات/مخرجات الأدوات كبصمات SHA-256 — المحتوى الخام يبقى محلياً؛ ولا يحمل تدفق الشاهد سوى بيانات نقاط التفتيش الوصفية، دون أي محتوى للسجلات.
- **فحوص اتساق دون اتصال**: أعد فحص البنية والعنونة بالمحتوى وروابط السلسلة وتوقيعات المنتِج من السجل وحده.
- **إثبات عبث بنقاط التفتيش**: كل نقطة تفتيش مقبولة تلتزم بتجزئة جذر السجل خارج بيئتك؛ وما بعدها غير مغطّى بعد. يوقف `CAPSULE_WITNESS=off` كل اتصال خارجي؛ ولا يرجع التحقق دون اتصال إلى أي نقطة تفتيش في الحالتين.
- **آمن للطاقم بالتصميم**: يحترم المستمع `is_replaying()` ولا يرفع استثناءات في تشغيل الطاقم؛ تعذُّر الوصول إلى خدمة الشفافية لا يمكن أن يكسر الطاقم.

## تعليمات الإعداد

<Steps>
    <Step title="ثبّت capsule-emit مع إضافة CrewAI">
      ```shell
      pip install "capsule-emit[crewai]"
      ```
    </Step>
    <Step title="سجّل المستمع">
      ```python
      from capsule_emit.adapters.crewai_listener import CapsuleEventListener

      # Register once, before kickoff — every tool call in the crew seals a capsule.
      listener = CapsuleEventListener(operator="acme-crew", developer="platform-team")
      ```
    </Step>
    <Step title="شغّل طاقمك كالمعتاد">
      ```python
      result = crew.kickoff()
      ```
      كل استدعاء أداة ينتج الآن سجلات مختومة وموقَّعة في السجل المحلي (`ledger.jsonl` افتراضياً).
    </Step>
    <Step title="افحص الأدلة">
      ```python
      import json
      from capsule_emit.signing import verify_store_signed

      rows = [json.loads(line) for line in open("ledger.jsonl") if line.strip()]
      if not rows:
          raise SystemExit("empty ledger — nothing to verify")
      # checks each signature against the key named in the record, not against a key you trust
      results = verify_store_signed([row.get("capsule", row) for row in rows], require_signature=True)
      ok = all(r.ok for r in results)
      print(f"{len(rows)} capsules, verify: {'ALL OK' if ok else 'FAILURES'}")
      ```
    </Step>
</Steps>

```shell
git clone --depth 1 --branch v0.8.6 https://github.com/action-state-group/capsule-emit.git
cd capsule-emit
pip install "capsule-emit[crewai]"
```

## ما الذي يُسجَّل

| الحقل | المحتوى |
|---|---|
| `action_id` / اسم الأداة | أي استدعاء أداة أو حدث دورة حياة الطاقم (بدء/اكتمال/فشل الانطلاق) تسجله هذه الكبسولة |
| بصمات المدخلات / المخرجات | التزامات SHA-256 — المحتوى الخام لا يغادر بيئتك أبداً |
| `effect` | `planned` أو `confirmed` أو `failed` في استدعاءات الأدوات (سجلات دورة حياة الطاقم بلا تأثير)؛ والحكم `executed` أو `errored` |
| سلسلة `confirms` | الكبسولة المؤكَّدة تستشهد بالكبسولة المخططة بعنوان المحتوى |
| `signature` / `key_id` | توقيع منتِج COSE_Sign1 على معرّف الكبسولة، والمفتاح الذي أنشأه — يقعان خارج البصمة، فيثبتان أي مفتاح وقّع، لا هوية حامله |
| الاتصال الخارجي | افتراضياً، نقطة تفتيش (حجم السجل، تجزئة الجذر، طابع زمني؛ دون أي محتوى للسجلات) بعد كل 100 سجل، أو عند الختم التالي بعد مرور 900 ثانية (لا يوجد مؤقت في الخلفية)، تُنشر إلى الشاهد العام للمشروع على `witness.agentactioncapsule.org`؛ يرسلها `CAPSULE_WITNESS_URL` إلى شاهد تختاره، ويعطّلها `CAPSULE_WITNESS=off`. المرساة القديمة لكل عملية ختم معطَّلة ما لم يُضبط `CAPSULE_ANCHOR=legacy-on` |

تنسيق السجل مواصفة مفتوحة (`draft-mih-scitt-agent-action-capsule`، مسودة إنترنت فردية لدى IETF) مع تنفيذ مرجعي برخصة Apache-2.0.
