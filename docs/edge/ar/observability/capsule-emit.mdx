# نظرة عامة على Agent Action Capsule

يقوم [capsule-emit](https://github.com/action-state-group/capsule-emit) بختم كل استدعاء أداة في تشغيل الطاقم كـ **Agent Action Capsule**: سجل أدلة موقّع ومعنون بالمحتوى (مخطط ← منفَّذ ← مؤكَّد) يمكن لطرف ثالث التحقق منه دون الوصول إلى النظام الذي أنتجه.

بينما تجيب أدوات التتبع والمراقبة في هذه الصفحة على سؤال *"ماذا حدث، للمشغّل"*، تجيب الكبسولات على سؤال *"أثبت ما حدث، لطرف لا يثق بالمشغّل"* — أدلة تدقيق وامتثال وليس تصحيح أخطاء. مكمّلة للتتبع، وليست بديلاً عنه.

### الميزات

- **مستمع واحد، كل استدعاء أداة**: سجّل `CapsuleEventListener()` مرة واحدة عبر آلية `BaseEventListener` القياسية في CrewAI — دون تغييرات في كود الأدوات.
- **سلاسل مخطط ← منفَّذ ← مؤكَّد**: تُختم كبسولة عند بدء استدعاء الأداة وتُؤكَّد بالبصمة عند انتهائه؛ الأخطاء تختم سجل تأثير فاشل.
- **خصوصية بالبصمات فقط**: تُلتزم مدخلات/مخرجات الأدوات كبصمات SHA-256 — المحتوى الخام يبقى محلياً؛ البصمات فقط تُرسَّخ في سجل شفافية SCITT.
- **تحقق دون اتصال**: تعيد `verify()` فحص كل كبسولة من السجل وحده — دون خدمة ودون بيانات اعتماد.
- **آمن للطاقم بالتصميم**: يحترم المستمع `is_replaying()` ولا يرفع استثناءات في تشغيل الطاقم؛ تعذُّر الوصول إلى المرساة لا يمكن أن يكسر الطاقم.

## تعليمات الإعداد

<Steps>
    <Step title="ثبّت capsule-emit مع إضافة CrewAI">
      ```shell
      pip install "capsule-emit[crewai]"
      ```
    </Step>
    <Step title="سجّل المستمع">
      ```python
      from capsule_emit.adapters.crewai_listener import CapsuleEventListener

      # Register once, before kickoff — every tool call in the crew seals a capsule.
      listener = CapsuleEventListener()
      ```
    </Step>
    <Step title="شغّل طاقمك كالمعتاد">
      ```python
      result = crew.kickoff()
      ```
      كل استدعاء أداة ينتج الآن سجلات مختومة في السجل المحلي (`ledger.jsonl` افتراضياً)، مع ترسيخ البصمات في خدمة شفافية SCITT المهيأة.
    </Step>
    <Step title="تحقق من الأدلة">
      ```python
      from capsule_emit import verify_ledger
      verify_ledger("ledger.jsonl")   # re-checks every capsule offline
      ```
    </Step>
</Steps>

## بداية سريعة قابلة للتشغيل

يأتي مع الحزمة عرض توضيحي محكم من البداية إلى النهاية (ناقل أحداث CrewAI حقيقي، خدمة شفافية محلية، دون مفتاح LLM ودون خدمة خارجية):

```shell
pip install "capsule-emit[crewai]"
python examples/crewai-listener/demo.py
```

الناتج المتوقع: تسلسل أحداث تشغيل طاقم مختوم في كبسولات — الانطلاق، سلسلة استدعاء أداة مخطط←مؤكَّد، سلسلة فاشل←خطأ — تنتهي بـ `verify: ALL OK`.

## ما الذي يُسجَّل

| الحقل | المحتوى |
|---|---|
| `action_id` / اسم الأداة | أي استدعاء أداة تسجله هذه الكبسولة |
| بصمات المدخلات / المخرجات | التزامات SHA-256 — المحتوى الخام لا يغادر بيئتك أبداً |
| `effect` | `planned` أو `executed` أو `confirmed` أو `errored` |
| سلسلة `confirms` | الكبسولة المنفَّذة تستشهد بالكبسولة المخططة بعنوان المحتوى |
| إيصال الترسيخ | تسجيل بالبصمات فقط في سجل شفافية SCITT (اختياري، مفعَّل افتراضياً) |

تنسيق السجل مواصفة مفتوحة (`draft-mih-scitt-agent-action-capsule`، مسودة إنترنت فردية لدى IETF) مع تنفيذ مرجعي برخصة Apache-2.0.
