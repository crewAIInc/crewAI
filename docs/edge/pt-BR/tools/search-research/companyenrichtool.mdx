## Configuração

Instale `crewai-tools` e defina `COMPANYENRICH_API_KEY` com uma chave do [painel CompanyEnrich](https://app.companyenrich.com/). Também é possível passar `api_key` ao criar a ferramenta. Adicione as ferramentas desejadas ao agente CrewAI.

## Ferramentas principais

| Ferramenta | Endpoint |
| --- | --- |
| `CompanyEnrichCompanyTool` | `GET /companies/enrich` |
| `CompanyEnrichSearchTool` | `POST /companies/search` |
| `CompanyEnrichSimilarTool` | `POST /companies/similar` |
| `CompanyEnrichPeopleSearchTool` | `POST /people/search` |
| `CompanyEnrichPersonLookupTool` | `POST /people/lookup` |
| `CompanyEnrichWorkforceTool` | `GET /companies/workforce` |
| `CompanyEnrichPropertiesTool` | `POST /companies/enrich` |
| `CompanyEnrichBatchTool` | `POST /companies/enrich/batch` |
| `CompanyEnrichCompanyByIdTool` | `GET /companies` |
| `CompanyEnrichPersonByIdTool` | `GET /people` |
| `CompanyEnrichSearchCountTool` | `POST /companies/search/count` |
| `CompanyEnrichSimilarCountTool` | `POST /companies/similar/count` |

## Uso

```python
from crewai_tools import (
    CompanyEnrichCompanyTool, CompanyEnrichPeopleSearchTool,
    CompanyEnrichSearchCountTool, CompanyEnrichAdvancedRequestTool,
)

profile = CompanyEnrichCompanyTool().run(domain="stripe.com", expand=["workforce"])
people = CompanyEnrichPeopleSearchTool().run(
    filters={"companyFilter": {"domains": ["stripe.com"]}}, expand=["education"], page_size=5
)
count = CompanyEnrichSearchCountTool().run(filters={"countries": ["US"]})
industries = CompanyEnrichAdvancedRequestTool().run(operation="get_industries")
```

## Entradas e resultados

As ferramentas de busca aceitam um objeto `filters` completo. A busca de empresas também aceita `semantic_query` (até 500 caracteres) e `query` (até 250). Entradas dedicadas não nulas têm precedência sobre campos correspondentes dos filtros; os demais campos são preservados. Use os arrays `expand` suportados (`workforce` para empresas e `education` para pessoas) e `wait_for_enrichment` nas rotas que o documentam. A consulta de funcionários exige exatamente um `company_id` ou `domain`. O enriquecimento em lote aceita 1–50 domínios; empresas semelhantes aceitam 1–10. IDs de empresas são UUIDs; IDs de pessoas aceitam inteiros int64 positivos ou strings decimais.

As buscas principais mantêm `page=1` e `page_size=5`. O tamanho aceita 1–100 e o produto da página pelo tamanho deve ser no máximo 10.000. Todos os campos da API e os metadados de paginação são preservados. Contagens retornam números, incluindo zero; resultados em lote e taxonomias mantêm arrays.

## Operações avançadas

`CompanyEnrichAdvancedRequestTool` aceita um enum fixo de 42 operações em `operation`, além de objetos opcionais `body`, `query` e `path_parameters`. Inclui operações principais, prévia/contagem/scroll, formação acadêmica, geografia/taxonomias, exportações assíncronas, enriquecimento em massa e ciclo de vida de tarefas. Exclui administração de listas salvas e `/me`. Operações e campos de consulta/caminho desconhecidos, identificadores inválidos e entradas obrigatórias de tarefas são rejeitados antes da requisição. Operações beta de e-mail exigem `allow_beta=True`. Requisições avançadas paginadas usam explicitamente página 1 e tamanho 10; exportações exigem contagem de 1 a 50.000.

Cada chamada faz uma requisição à API HTTPS fixa do CompanyEnrich, com `timeout` configurável (30 segundos por padrão). Não há novas tentativas, paginação, polling ou download de URLs de resultados automáticos. As operações podem consumir créditos; consulte a [referência da API](https://docs.companyenrich.com/reference) para schemas e preços atuais. Falhas HTTP são propagadas com mensagens sanitizadas, sem a chave da API ou o corpo original do erro.
