# `SerpKiteSearchTool`

Esta integração é mantida pela equipe SerpKite e distribuída em `serpkite[crewai]`. Ela não faz parte de `crewai-tools`.

## Instalação

Instale o pacote e defina `SERPKITE_API_KEY` com uma chave do [SerpKite](https://app.serpkite.com/keys).

```shell
uv add "serpkite[crewai]"
export SERPKITE_API_KEY="skt_live_..."
```

## Uso

A ferramenta retorna Markdown com resultados de pesquisa e links das fontes. Passe-a diretamente para um agente CrewAI. Configure seu provedor de LLM preferido separadamente.

```python
from crewai import Agent
from serpkite.crewai import SerpKiteSearchTool

search = SerpKiteSearchTool()
print(search.run(query="latest Python release"))

researcher = Agent(
    role="Researcher",
    goal="Find current information and cite sources",
    backstory="You research public information using web search.",
    tools=[search],
)
```

## Configuração

Use `endpoint` para escolher `search` (padrão), `news`, `images`, `videos`, `maps`, `places`, `shopping`, `scholar`, `patents` ou `autocomplete`. Defina `country`, `language`, `location` e `num` como valores padrão. O agente pode fornecer `query`, `num`, `country`, `language` e `time` (`hour`, `day`, `week`, `month`, `year`).

```python
news = SerpKiteSearchTool(endpoint="news", country="us", language="en", num=10)
print(news.run(query="renewable energy", time="week"))
```
