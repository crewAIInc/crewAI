A integração é fornecida pela Ace Data Cloud; não é um produto oficial da Suno ou da CrewAI. O código está em revisão, sem lançamento PyPI ou listagem AMP confirmados.

Instale o pacote independente a partir do commit exato revisado. Ele usa CrewAI BaseTool diretamente, sem configurar MCP ou escrever um wrapper.

```bash
uv add 'crewai-suno @ git+https://github.com/AceDataCloud/SunoCrewAI.git@000cb3b7671dceb3ef52f7bd59259700f57f61cf'
```

Cadastre-se ou entre em [Ace Applications](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=sunocrewai_docs_api_key). Abra General application e copie um Token de consumo da API, ou use Manage Keys → Create. Se restringir APIs, permita `/suno/audios` e `/suno/tasks`. Defina `ACEDATACLOUD_API_KEY` no ambiente; nunca inclua a chave em prompts ou configurações versionadas.

Confira acesso ao Suno, saldo e [preços dos modelos](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=sunocrewai_docs_pricing). Adicionar uma ferramenta não a executa. `SunoGenerateMusicTool` envia uma solicitação assíncrona paga uma vez; `SunoRetrieveTaskTool` consulta somente o ID original. pending não é sucesso.

Para a primeira verificação segura, consulte uma tarefa que já seja sua; isso não cria música.

```python
from suno_crewai import SunoRetrieveTaskTool

result = SunoRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```

Após aprovar o orçamento, passe `SunoGenerateMusicTool()` e `SunoRetrieveTaskTool()` ao Agent. A geração exige um ID público e atual de modelo e retorna task_id; preserve esse ID. Não gere novamente para consultar nem após um timeout de resultado desconhecido. Cada instância gera uma vez por padrão; isso não é um limite financeiro.

A consulta bem-sucedida retorna status=succeeded, success=true, media_urls e o cost original em Credits, quando fornecido. Falhas usam ToolFailure. HTTP 401/403/429/5xx mantêm seu significado; não há repetição automática de HTTP pago nem fallback de modelo. O pacote não habilita tracing nem adiciona GUI.
