A Ace Data Cloud mantém este pacote para usar HappyHorse com o CrewAI.

## Instalação

```bash
uv add crewai-happyhorse==0.1.0
```

Crie um [token de API de aplicativo](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=happyhorsecrewai_docs_api_key) com acesso a HappyHorse e defina `ACEDATACLOUD_API_KEY` no ambiente. Consulte o [preço atual](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=happyhorsecrewai_docs_pricing) antes de gerar mídia.

## Uso

Preserve ações generate/image_to_video/reference_to_video/video_edit e referências exigidas image_url/image_urls/video_url. Resolução720P/1080P, duração3..15. Saída lista data com video_url/state.

Adicione `HappyHorseGenerateVideoTool()` e `HappyHorseRetrieveTaskTool()` à lista `tools` do agente. A geração retorna um ID de tarefa. Para acompanhar o progresso, consulte o mesmo ID com a chave que enviou a tarefa.

```python
from happyhorse_crewai import HappyHorseRetrieveTaskTool

result = HappyHorseRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```
