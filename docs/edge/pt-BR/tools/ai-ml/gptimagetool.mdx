A Ace Data Cloud mantém este pacote para usar GPT Image com o CrewAI.

## Instalação

```bash
uv add crewai-gpt-image==0.1.0
```

Crie um [token de API de aplicativo](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=gptimagecrewai_docs_api_key) com acesso a GPT Image e defina `ACEDATACLOUD_API_KEY` no ambiente. Consulte o [preço atual](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=gptimagecrewai_docs_pricing) antes de gerar mídia.

## Uso

GPT Image usa size/quality/n(1..10), background e formato; /openai/images/generations com response_format=url. Não é DallETool ou Nano Banana. Saída data[].url; edição multipart não incluída.

Adicione `GPTImageGenerateImageTool()` e `GPTImageRetrieveTaskTool()` à lista `tools` do agente. A geração retorna um ID de tarefa. Para acompanhar o progresso, consulte o mesmo ID com a chave que enviou a tarefa.

```python
from gpt_image_crewai import GPTImageRetrieveTaskTool

result = GPTImageRetrieveTaskTool().run(task_id="YOUR_EXISTING_TASK_ID", wait_seconds=0)
print(result)
```
