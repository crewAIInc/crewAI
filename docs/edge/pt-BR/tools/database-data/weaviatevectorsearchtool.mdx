## Visão Geral

O `WeaviateVectorSearchTool` foi especificamente desenvolvido para realizar buscas semânticas em documentos armazenados em um banco de dados vetorial Weaviate. Essa ferramenta permite encontrar documentos semanticamente similares a uma determinada consulta, aproveitando o poder das embeddings vetoriais para resultados de busca mais precisos e contextualmente relevantes.

[Weaviate](https://weaviate.io/) é um banco de dados vetorial que armazena e consulta embeddings vetoriais, possibilitando recursos de busca semântica.

## Instalação

Para incorporar esta ferramenta ao seu projeto, é necessário instalar o cliente Weaviate:

```shell
uv add weaviate-client
```

## Etapas para Começar

Para utilizar efetivamente o `WeaviateVectorSearchTool`, siga as etapas abaixo:

1. **Instalação dos Pacotes**: Confirme que os pacotes `crewai[tools]` e `weaviate-client` estão instalados em seu ambiente Python.
2. **Configuração do Weaviate**: Configure um cluster Weaviate Cloud seguindo a [documentação do Weaviate](https://weaviate.io/developers/wcs/manage-clusters/connect), ou execute o Weaviate por conta própria (por exemplo, com Docker).
3. **Chaves de API**: Para o Weaviate Cloud, obtenha a URL do seu cluster e a chave de API.
4. **Chave de API da OpenAI (opcional)**: Se a sua coleção vetoriza com a OpenAI, defina `OPENAI_API_KEY` no seu ambiente. A ferramenta a repassa ao Weaviate. Coleções que usam outro vetorizador não precisam dela.

## Exemplo

O exemplo a seguir demonstra como inicializar a ferramenta e executar uma busca:

```python Code
from crewai_tools import WeaviateVectorSearchTool

# Inicializar a ferramenta
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)

@agent
def search_agent(self) -> Agent:
    '''
    Este agente utiliza o WeaviateVectorSearchTool para buscar 
    documentos semanticamente similares em um banco de dados vetorial Weaviate.
    '''
    return Agent(
        config=self.agents_config["search_agent"],
        tools=[tool]
    )
```

## Parâmetros

O `WeaviateVectorSearchTool` aceita os seguintes parâmetros:

- **collection_name**: Obrigatório. O nome da coleção a ser pesquisada.
- **weaviate_cluster_url**: Opcional. A URL de um cluster Weaviate Cloud. Quando não é definida, a ferramenta se conecta a um Weaviate auto-hospedado em `weaviate_host`.
- **weaviate_api_key**: Opcional. A chave de API para o cluster Weaviate. Obrigatória com `weaviate_cluster_url`.
- **weaviate_host**: Opcional. Host de um Weaviate auto-hospedado. O padrão é `localhost`.
- **weaviate_http_port** / **weaviate_grpc_port**: Opcional. Portas de um Weaviate auto-hospedado. Os padrões são `8080` e `50051`.
- **weaviate_secure**: Opcional. Usa HTTPS e gRPC com TLS para um Weaviate auto-hospedado. O padrão é `False`.
- **headers**: Opcional. Headers extras enviados ao Weaviate, como chaves de API de provedores de modelos.
- **search_type**: Opcional. `hybrid` (vetorial e por palavra-chave), `near_text` (somente vetorial) ou `bm25` (somente por palavra-chave). O padrão é `hybrid`.
- **limit**: Opcional. O número de resultados a serem retornados. O padrão é `3`.
- **alpha**: Opcional. Para a busca `hybrid`, controla o peso entre a busca vetorial e a busca por palavra-chave (BM25). alpha = 0 -> somente BM25, alpha = 1 -> somente busca vetorial. O padrão é `0.75`.
- **target_vector**: Opcional. O vetor nomeado, ou lista de vetores nomeados, a ser pesquisado em coleções com mais de um vetor.
- **return_properties**: Opcional. As propriedades a serem retornadas para cada resultado. Por padrão, retorna todas as propriedades.
- **filters**: Opcional. Um `weaviate.classes.query.Filter` aplicado a todas as buscas.
- **tenant**: Opcional. O tenant a ser pesquisado em uma coleção multi-tenant.
- **create_collection_if_missing**: Opcional. Cria a coleção com `vectorizer` e `generative_model` caso ela não exista. O padrão é `False`.
- **vectorizer**: Opcional. A configuração de vetores usada quando a ferramenta cria a coleção. O padrão é `Configure.Vectors.text2vec_openai(model="text-embedding-3-small")`.
- **generative_model**: Opcional. O modelo generativo usado quando a ferramenta cria a coleção. O padrão é o `gpt-4o` da OpenAI.

## Weaviate Auto-hospedado

Omita `weaviate_cluster_url` para se conectar a um Weaviate que você mesmo executa:

```python Code
from crewai_tools import WeaviateVectorSearchTool

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    weaviate_host="localhost",
    weaviate_http_port=8080,
    weaviate_grpc_port=50051,
)
```

Defina `weaviate_secure=True` quando o seu Weaviate for servido via HTTPS. Informe `weaviate_api_key` se ele exigir autenticação.

## Opções de Busca

Escolha o tipo de busca, o vetor nomeado a ser pesquisado e as propriedades a serem retornadas, e filtre os resultados:

```python Code
from crewai_tools import WeaviateVectorSearchTool
from weaviate.classes.query import Filter

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    search_type="near_text",
    target_vector="body_vector",
    return_properties=["title", "body"],
    filters=Filter.by_property("year").greater_than(2020),
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

## Multi-tenancy

Para uma [coleção multi-tenant](https://docs.weaviate.io/weaviate/manage-collections/multi-tenancy), defina `tenant` para pesquisar apenas os dados desse tenant:

```python Code
tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    tenant="customer_a",
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

O tenant é definido quando você cria a ferramenta, e não pelo agente, portanto um agente não consegue ler os dados de outro tenant.

## Criando a Coleção e Quantização

Por padrão, a ferramenta apenas pesquisa coleções existentes. Defina `create_collection_if_missing=True` para que ela crie a coleção no primeiro uso. A ferramenta usa `vectorizer` e `generative_model` para a nova coleção, torna-a multi-tenant quando `tenant` está definido e cria esse tenant.

`vectorizer` aceita qualquer configuração de `Configure.Vectors`, então você também pode escolher a [quantização vetorial](https://docs.weaviate.io/weaviate/configuration/compression) aqui. Este exemplo usa modelos locais servidos pelo Ollama e quantização escalar:

```python Code
from crewai_tools import WeaviateVectorSearchTool
from weaviate.classes.config import Configure

tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    create_collection_if_missing=True,
    vectorizer=Configure.Vectors.text2vec_ollama(
        api_endpoint="http://host.docker.internal:11434",
        model="nomic-embed-text",
        quantizer=Configure.VectorIndex.Quantizer.sq(),
    ),
    generative_model=Configure.Generative.ollama(
        api_endpoint="http://host.docker.internal:11434",
        model="llama3.2",
    ),
)
```

Os outros quantizadores são `Configure.VectorIndex.Quantizer.rq()`, `.bq()` e `.pq()`.

## Pré-carregando Documentos

Você pode pré-carregar seu banco de dados Weaviate com documentos antes de utilizar a ferramenta:

```python Code
import os
from crewai_tools import WeaviateVectorSearchTool
import weaviate
from weaviate.classes.config import Configure
from weaviate.classes.init import Auth

# Conectar ao Weaviate
client = weaviate.connect_to_weaviate_cloud(
    cluster_url="https://your-weaviate-cluster-url.com",
    auth_credentials=Auth.api_key("your-weaviate-api-key"),
    headers={"X-OpenAI-Api-Key": "your-openai-api-key"}
)

# Obter ou criar coleção
if client.collections.exists("example_collections"):
    test_docs = client.collections.get("example_collections")
else:
    test_docs = client.collections.create(
        name="example_collections",
        vector_config=Configure.Vectors.text2vec_openai(model="text-embedding-3-small"),
        generative_config=Configure.Generative.openai(model="gpt-4o"),
    )

# Carregar documentos
docs_to_load = os.listdir("knowledge")
with test_docs.batch.dynamic() as batch:
    for d in docs_to_load:
        with open(os.path.join("knowledge", d), "r") as f:
            content = f.read()
        batch.add_object(
            {
                "content": content,
                "year": d.split("_")[0],
            }
        )

# Inicializar a ferramenta
tool = WeaviateVectorSearchTool(
    collection_name='example_collections', 
    limit=3,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)
```

## Exemplo de Integração com Agente

Veja como integrar o `WeaviateVectorSearchTool` com um agente CrewAI:

```python Code
from crewai import Agent
from crewai_tools import WeaviateVectorSearchTool

# Inicializar a ferramenta
weaviate_tool = WeaviateVectorSearchTool(
    collection_name='example_collections',
    limit=3,
    weaviate_cluster_url="https://your-weaviate-cluster-url.com",
    weaviate_api_key="your-weaviate-api-key",
)

# Criar um agente com a ferramenta
rag_agent = Agent(
    name="rag_agent",
    role="Você é um assistente útil que pode responder perguntas com a ajuda do WeaviateVectorSearchTool.",
    llm="gpt-4o-mini",
    tools=[weaviate_tool],
)
```

## Conclusão

O `WeaviateVectorSearchTool` fornece uma maneira poderosa de buscar documentos semanticamente similares em um banco de dados vetorial Weaviate. Ao utilizar embeddings vetoriais, ele permite resultados de busca mais precisos e relevantes em termos de contexto, quando comparado a buscas tradicionais baseadas em palavras-chave. Essa ferramenta é especialmente útil para aplicações que precisam encontrar informações a partir do significado e não apenas de correspondências exatas.
