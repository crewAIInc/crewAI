# Ferramentas de Memória de Agente Lians

O [Lians](https://www.lians.ai/) fornece quatro ferramentas CrewAI para armazenar, recuperar, reproduzir e persistir a memória do agente. Ele pode ser executado localmente sem chave de API ou conectado a um serviço Lians remoto.

## Instalação

Instale o CrewAI e a integração do Lians com o CrewAI. Inclua o extra `local` para obter armazenamento local sem configuração.

```bash
pip install crewai "lians-sdk[crewai,local]"
```

## Uso

Crie um cliente local, construa as ferramentas e associe-as a um agente.

```python
from crewai import Agent, Crew, Task
from lians import LocalLiansClient
from lians.crewai_integration import build_crewai_tools

with LocalLiansClient() as client:
    memory_tools = build_crewai_tools(client, agent_id="research-crew")

    researcher = Agent(
        role="Researcher",
        goal="Build on verified findings from earlier research",
        backstory="You preserve useful evidence and retrieve it when relevant.",
        tools=memory_tools,
        verbose=True,
    )

    task = Task(
        description="Research the topic, recall relevant prior findings, and save new evidence.",
        expected_output="A concise research brief with the useful findings saved to memory.",
        agent=researcher,
    )

    result = Crew(agents=[researcher], tasks=[task]).kickoff()
    print(result)
```

## Ferramentas disponíveis

| Ferramenta | Finalidade |
|:-----|:--------|
| `remember_fact` | Armazenar um fato com metadados de origem e confiança |
| `recall_facts` | Recuperar memórias relevantes para a consulta atual |
| `recall_facts_at` | Reconstruir o que o agente sabia em um momento específico |
| `flush_memory` | Persistir atualizações de memória pendentes |

Use um `agent_id` estável quando várias execuções da crew precisarem compartilhar o mesmo histórico de memória. Use outro ID quando as execuções precisarem de memórias isoladas.

## Serviço remoto

Para usar um serviço Lians implantado, crie o cliente Lians padrão com a URL do serviço e as credenciais e passe-o para `build_crewai_tools` no lugar de `LocalLiansClient`.

```python
import os

from lians import LiansClient
from lians.crewai_integration import build_crewai_tools

with LiansClient(
    base_url=os.environ["LIANS_BASE_URL"],
    api_key=os.environ["LIANS_API_KEY"],
) as client:
    memory_tools = build_crewai_tools(client, agent_id="research-crew")
    # Crie e execute o Agent/Crew dentro deste bloco para manter o cliente aberto.
```

Para obter detalhes de configuração e API, consulte a [documentação do Lians](https://www.lians.ai/docs).
