# `ZenRowsScrapeTool`

## Descrição

[Zenrows](https://www.zenrows.com/) é uma API de web scraping que trata o bypass de anti-bot, a renderização de JavaScript com navegador headless e a rotação de proxies residenciais por trás de um único endpoint HTTP. A `ZenRowsScrapeTool` raspa uma URL e retorna seu conteúdo como markdown, texto simples ou HTML bruto.

Por padrão, toda requisição é enviada no [Adaptive Stealth Mode](https://docs.zenrows.com/universal-scraper-api/features/adaptive-stealth-mode) (`mode: "auto"`): o Zenrows começa com a configuração mais barata possível e escala automaticamente para renderização JS ou proxies premium apenas quando a página-alvo precisa, cobrando apenas pela configuração que teve sucesso. Essa é uma escolha de design deliberada para esta tool — ela mantém a superfície visível ao agente restrita a `url` e `response_type`, em vez de uma longa lista de parâmetros anti-bot (`js_render`, `premium_proxy`, `proxy_country`, ...) que um LLM não tem como escolher corretamente para cada página.

## Instalação

- Obtenha uma chave de API em [zenrows.com](https://www.zenrows.com/) e defina-a na variável de ambiente `ZENROWS_API_KEY` (ou passe `api_key=` explicitamente).
- Nenhum pacote extra é necessário — a tool usa `requests`, que já é uma dependência de `crewai-tools`.

```shell
pip install 'crewai[tools]'
```

## Exemplo

```python Code
from crewai_tools import ZenRowsScrapeTool

tool = ZenRowsScrapeTool()

result = tool.run(url="https://example.com")
```

Solicitando texto simples em vez do markdown padrão:

```python Code
result = tool.run(url="https://example.com", response_type="plaintext")
```

## Configuração avançada

Parâmetros que uma crew específica sempre precisa — executar `js_instructions`, aguardar um seletor, ou desativar o Adaptive Stealth em favor de `js_render`/`premium_proxy`/`proxy_country` fixados manualmente — são definidos uma vez na construção via `config` e passam a valer para toda requisição feita por essa instância da tool.

<Note>
  `proxy_country` exige `premium_proxy: True` — o Zenrows só aplica geolocalização a proxies premium (residenciais), então `proxy_country` sozinho é silenciosamente ignorado. Também não pode ser combinado com `mode: "auto"`, já que o Adaptive Stealth Mode gerencia `premium_proxy` por conta própria e rejeita a requisição se ele também for definido manualmente. A `ZenRowsScrapeTool` valida isso no momento da construção e levanta um `ValueError` em vez de falhar silenciosamente ou apenas no momento da requisição.
</Note>

```python Code
tool = ZenRowsScrapeTool(
    config={
        "premium_proxy": True,
        "proxy_country": "us",
    }
)
```

Para ter controle manual total em vez do Adaptive Stealth:

```python Code
tool = ZenRowsScrapeTool(
    config={
        "js_render": True,
        "premium_proxy": True,
        "proxy_country": "us",
    }
)
```

Consulte a [documentação da API do Zenrows](https://docs.zenrows.com/universal-scraper-api/api-reference) para a referência completa de parâmetros.

## Argumentos

- `api_key`: Opcional. Sua chave de API do Zenrows. Padrão é a variável de ambiente `ZENROWS_API_KEY`.
- `config`: Opcional. Parâmetros extras da API do Zenrows mesclados em toda requisição feita por essa instância da tool. Padrão é `{"mode": "auto"}` (Adaptive Stealth Mode).
- `timeout`: Opcional. Timeout da requisição em segundos. Padrão é `140` para acomodar páginas renderizadas via JS.

Argumentos por chamada (visíveis ao agente):

- `url`: Obrigatório. URL completa da página a ser raspada, incluindo o esquema.
- `response_type`: Opcional. Um de `"markdown"` (padrão), `"plaintext"`, ou `"html"`.
