# Recibos sebbi para CrewAI

O [sebbi](https://sebbi.pro/receipts) dá a cada etapa da sua crew um recibo selado com um link público que qualquer pessoa pode verificar: seu cliente, seu auditor, sua seguradora ou um regulador. Os recibos são agrupados em árvores de Merkle, selados em uma cadeia somente de acréscimo, testemunhados por cadeias independentes e com carimbo de tempo no Bitcoin, de modo que o registro do que um agente fez não pode ser alterado silenciosamente depois.

O cliente sebbi calcula o hash (SHA-256) das entradas e saídas dentro do seu processo e envia apenas as impressões digitais, um rótulo curto e um carimbo de tempo. O cliente é de código aberto, então você pode confirmar isso antes de instalar: [github.com/justrightdecorators-ops/sebbi-sdk](https://github.com/justrightdecorators-ops/sebbi-sdk). A selagem roda em uma thread em segundo plano e nunca gera exceções na sua crew.

## Instalação

Fixe a versão que você revisou:

```bash
pip install "sebbi==1.1.1"
```

A versão na branch `main` desse repositório é a versão publicada no PyPI, então você pode ler exatamente o que vai instalar. O cliente não tem dependências.

Não é preciso conta para começar (1.000 recibos por dia). Defina `SEBBI_API_KEY` em [sebbi.pro/connect](https://sebbi.pro/connect) para volume completo.

## Uso

```python
from crewai import Agent, Crew, Task
from sebbi.integrations.crewai import step_callback, task_callback

crew = Crew(
    agents=[...],
    tasks=[...],
    step_callback=step_callback,   # um recibo para cada etapa do agente
    task_callback=task_callback,   # um recibo para cada tarefa concluída
)

result = crew.kickoff()
```

Obtenha o link do recibo mais recente:

```python
import sebbi
print(sebbi.last().url)   # https://sebbi.pro/r/...
```

## Selando uma ação específica

Envolva qualquer função de ferramenta que seus agentes chamam:

```python
import sebbi

@sebbi.receipt("issue-refund")
def issue_refund(order_id: str, amount: float) -> dict:
    ...
```

## Estornos

Se uma ação for desfeita (um reembolso, um pagamento cancelado), sele o estorno. O recibo original permanece registrado e aparece como estornado, vinculado ao novo recibo e ao motivo:

```python
sebbi.reverse(receipt, "Cliente cancelou; reembolso devolvido")
```

## Verificando um recibo

Abra o link do recibo ou chame `GET https://sebbi.pro/v1/receipts/<id>`. Cada verificação refaz a prova de inclusão de Merkle e confirma que a raiz está selada na cadeia.
