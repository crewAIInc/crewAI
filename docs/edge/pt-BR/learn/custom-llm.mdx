## Visão Geral

O CrewAI oferece suporte a implementações personalizadas de LLM por meio da classe abstrata `BaseLLM`. Isso permite integrar qualquer provedor de LLM que não tenha suporte nativo no LiteLLM ou implementar mecanismos de autenticação personalizados.

## Início rápido offline (sem chave de API)

Use este stub determinístico para aprender a interface `BaseLLM` e validar a integração `Agent` / `Task` / `Crew` **sem** credenciais de provedor ou chamadas HTTP ao modelo. É apenas para aprendizado e testes — substitua o corpo de `call()` pela requisição à API do seu provedor quando for para produção.

```python
from typing import Any

from crewai import Agent, BaseLLM, Crew, Process, Task


class OfflineStubLLM(BaseLLM):
    """Offline stub for learning and tests — not for production use."""

    def __init__(
        self,
        response: str = "Hello from OfflineStubLLM!",
        model: str = "offline-stub",
    ) -> None:
        super().__init__(model=model)
        self.response = response

    def call(
        self,
        messages: str | list[dict[str, Any]],
        tools: list[dict[str, Any]] | None = None,
        callbacks: list[Any] | None = None,
        available_functions: dict[str, Any] | None = None,
        from_task: Any = None,
        from_agent: Any = None,
        response_model: Any = None,
    ) -> str:
        # Replace this block with your provider's HTTP/API call.
        if "Thought:" in str(messages):
            return (
                "Thought: Using the offline stub.\n"
                f"Final Answer: {self.response}"
            )
        return self.response

    def supports_function_calling(self) -> bool:
        return False

    def supports_stop_words(self) -> bool:
        return False

    def get_context_window_size(self) -> int:
        return 4096

    async def acall(self, *args: Any, **kwargs: Any) -> str:
        raise NotImplementedError


def main() -> None:
    llm = OfflineStubLLM()

    direct = llm.call("Say hi without an API key.")
    print(f"Direct call: {direct}")

    agent = Agent(
        role="Greeter",
        goal="Return a friendly greeting",
        backstory="You respond with the stub greeting.",
        llm=llm,
    )
    task = Task(
        description="Say hello to the user",
        expected_output="A short greeting",
        agent=agent,
    )
    crew = Crew(
        agents=[agent],
        tasks=[task],
        process=Process.sequential,
        verbose=False,
    )
    result = crew.kickoff()
    print(f"Crew result: {result.raw}")


if __name__ == "__main__":
    main()
```

### Executar o exemplo

Salve o script acima como `offline_custom_llm.py` na raiz do repositório (após `uv sync`) e execute:

```bash
uv run python offline_custom_llm.py
```

Você também pode rodar o smoke check correspondente na suíte de testes (sem chave de API ou cassette VCR):

```bash
uv run pytest lib/crewai/tests/test_custom_llm.py::test_offline_custom_llm_quick_start_smoke -q
```

**Saída esperada** (pode aparecer também uma linha de log sobre contagem aproximada de tokens para modelos customizados):

```text
Direct call: Hello from OfflineStubLLM!
Crew result: Hello from OfflineStubLLM!
```

## Solução de Problemas

### Problemas Comuns

**Erros no Construtor**
```python
# ❌ Errado - parâmetros obrigatórios ausentes
def __init__(self, api_key: str):
    super().__init__()

# ✅ Correto
def __init__(self, model: str, api_key: str, temperature: Optional[float] = None):
    super().__init__(model=model, temperature=temperature)
```

**Chamada de Funções Não Funciona**
- Certifique-se de que `supports_function_calling()` retorna `True`
- Verifique se você lida com `tool_calls` na resposta
- Assegure-se de que o parâmetro `available_functions` está sendo corretamente utilizado

**Falhas de Autenticação**
- Verifique o formato e as permissões da chave de API
- Confira o formato do header de autenticação
- Certifique-se de que as URLs dos endpoints estão corretas

**Erros de Parsing de Resposta**
- Valide a estrutura da resposta antes de acessar campos aninhados
- Trate casos em que o content pode ser None
- Adicione tratamento de erros para respostas malformadas
